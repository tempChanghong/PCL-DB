# PCL-DB Beta 4.0

Plain Craft Launcher - Download Bridge 的第四个 Beta，标签为 `v4.0.0-beta.1`，应用内显示 **Beta 4.0**。本版以 PCL2 风格为核心，补齐外部启动器支持，并集中改进下载、详情页面的动画与交互。

这是独立的第三方下载补全工具。安装完成后，继续使用所选启动器启动游戏。

## 相比 Beta 3.0

- **支持 PCL、HMCL、PCL-CE。**「设置 → 外部启动器」独立管理多份启动器及其游戏目录，只读外部目录配置；任务开始时固定目标，避免下载中切换目录影响进行中的任务。HMCL、PCL-CE 接入原生隔离、组件、整合包安装及已有原版实例补全，保留已有实例配置。
- **可跟随 PCL 当前主题。** 在个性化中明确选择一份 PCL 配置，后台只读刷新已保存的主题；支持的配色自动同步，未知主题、读取失败或文件占用时回退本机外观，恢复后继续跟随。本机深色模式、透明度和背景选项保留。
- **下载与返回动画更完整。** 补齐安装页和任务页的逐卡片退场、交接与错峰入场，下载按钮独立弹出和按压回弹；返回保留名称、组件和视口。卡片悬停、箭头旋转、快速反向和旧动画清理继续对照 PCL2。
- **搜索与详情交互更稳定。** 改进搜索区分层、明暗提示条和紧凑次要按钮；修复连续滚轮丢失、筛选栏与整页滚动冲突、弹窗返回焦点，以及隐藏页面收到旧搜索、分页或点击事件的问题。复制名称按限次策略异步重试，浏览器打开失败时可回退复制网址。
- **统一历史版本来源标记。** 补充版本显示灰色「UVMC 特供下载」标签；Minecraft 2.0 保留 `2.0 (Blue)`、`2.0 (Red)`、`2.0 (Purple)` 三个独立身份、年份和颜色区别，按原分类与时间排列。补充源失败不影响普通版本列表。

## 下载与升级

直接运行 `PCL-DB-4.0.0-beta.1.exe`，或解压 ZIP 后运行其中的 `PCL-DB.exe`。两者使用同一个单 EXE，系统仍需安装 **.NET Framework 4.8**。应用没有数字签名。

关闭旧版后替换程序；保留已有设置和游戏目录。首次使用 HMCL / PCL-CE 时，在外部启动器卡片中选择对应位置并确认游戏目录。仅替换下载补全工具，无需移动已安装的 Minecraft。

- `PCL-DB-4.0.0-beta.1.exe`：单文件程序。

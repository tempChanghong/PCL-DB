# PCL-DB Beta 8.0

Plain Craft Launcher - Download Bridge 的第八个 Beta，标签 `v8.0.0-beta.1`，应用内显示 **Beta 8.0**。本版集中修复管理、搜索、下载任务与动画之间的连续操作问题，界面和交互继续以 PCL2 为核心。

## 相比 Beta 7.0

- **快速切换与返回更可靠。** 分类切换、搜索提交、资源详情、前置链接和返回历史先绑定当前操作，再通知旧请求取消。较新的搜索、页面和读取优先，旧结果不再抢回页面或覆盖提示。
- **管理与 Mod 操作交接更完整。** 处理实例选择、目录快捷方式、管理列表刷新、Mod 读取和文件操作结束后的同步回调；读取和写入保持各自归属，保留原生隔离设置。同一物理目录下的 PCL、HMCL、PCL-CE 绑定继续分别识别，切换期间不清空后来接受的实例页或结束其动画。
- **安装开始失败后可以恢复。** 原版、本地 ZIP/MRPACK、在线整合包与资源任务在准备界面和退出旧读取时发生异常，会结束所属任务并恢复可重试状态。任务页入场失败后清理旧页面、侧栏和工具栏，返回标题与内容重新一致。
- **资源安装结果更准确。** 文件成功安装后，本地列表刷新或取消观察者报错不再把成功显示为失败；结束通知也不会跳过忙碌状态释放。去除重复失效，取消、失败与重新安装继续保留原任务目标和诊断。
- **任务信息与反馈不串台。** 进度刷新保留原任务名称，资源另存为和指定实例安装采用对应文案；打开目录、日志和复制信息后的反馈不覆盖较新任务。
- **打包保留完整验证信息。** 构建清单默认采用紧凑 JSON，保留全部检查断言，无需依赖调用进程的 JSON 格式覆盖。完整回执增长后，原先的 1 MiB 清单上限会拒绝合法工件，本版将读写边界统一扩大到 4 MiB，继续检查字节长度与工件绑定；修正 README 中旧版下载链接。

原版与组件安装、CurseForge ZIP / Modrinth MRPACK 导入、社区资源搜索及指定实例安装、本地 Mod 管理和更新继续提供。PCL、HMCL、PCL-CE 的外部配置仍只读，已有实例和文件按原机制保留；本版不新增启动游戏或自动补装前置功能。

发布验证的各套件和重试使用独立临时目录，避免 UI、动画和搜索夹具中的同名文件冲突，保留每轮原始证据。

## 下载与升级

关闭旧版后直接运行 **`PCL-DB-8.0.0-beta.1.exe`**；或下载 ZIP，解压后运行其中的 `PCL-DB.exe`。两个入口使用同一份单 EXE，系统需安装 **.NET Framework 4.8**，程序未做数字签名。无需搬迁已有游戏目录，升级后确认所选启动器与目标目录即可。

附件包含单 EXE、便携 ZIP、源码 ZIP、构建清单、`verification.json`、本说明副本与 `SHA256SUMS.txt`。源码支持 Visual Studio 2026；便携 ZIP 附许可和使用文档，历史发行保持原样。

## 验证范围

发布流程对确切的单 EXE 候选执行完整界面、动画、搜索和独立运行检查，核心检查使用与候选内嵌字节一致的 Core。随检查规模增长，完整界面／动画／导航使用 60 分钟有界总期限，搜索为 30 分钟；大型导航／返回／搜索提交／Mod 写入启动矩阵为 180 秒，单次异步等待和应用网络期限保持。在 PowerShell 7 / Windows PowerShell 5.1 验证该候选的打包行为，并在仓库外构建对应源码归档。具体计数、源码提交、候选摘要及边界见附件 `verification.json`，套件计数存在重叠。上传后从公开地址重新下载所有附件并核对 SHA-256。

验证使用临时实例、原生配置夹具、受控网络及实际 WPF 时钟／离屏布局，不替代完整游戏启动、所有 Mod／加载器组合、真实网络可用性和人工桌面帧率验收。项目为独立第三方工具，来源、许可与致谢见随附文档。

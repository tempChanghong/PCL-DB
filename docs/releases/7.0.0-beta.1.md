# PCL-DB Beta 7.0

Plain Craft Launcher - Download Bridge 的第七个 Beta，标签 `v7.0.0-beta.1`，应用内显示 **Beta 7.0**。本版集中改善 Mod 管理的动画和连续操作，修复管理、搜索、安装之间的状态冲突，界面继续以 PCL2 为核心。

## 相比 Beta 6.0

- **Mod 选择动画更完整。** 补齐选中色条的弹性展开、标题渐变和按压反馈；全选与取消选择直接更新当前行，避免重建列表打断动画。重复清理不再提前收起底栏，退场保留原计数。批量选择时屏外行直接应用最终状态，减少无效动画。
- **在线更新信息不再打断选择。** 普通列表及“可更新”列表在成员与顺序不变时就地刷新信息，保留正在运行的选中动画；实际增减更新项时正常刷新筛选并清理不可见选择。连续 Ctrl+A 保持全选，含文字的搜索框继续使用文本全选。
- **确认窗口和键盘焦点更连贯。** Mod 更新确认沿用 PCL2 的遮罩、位移、旋转和退场时序。文件操作等待所属确认窗口真正退出；重复取消或新弹窗替代旧弹窗，不会意外启动旧操作。取消选择、批量操作完成或失败后恢复可用列表焦点并保留滚动位置，较新的搜索和页面焦点优先。
- **修复快速切换与取消重试。** 管理刷新、补全准备、Mod 扫描与写入，以及资源搜索、详情、前置查询和存档选择，先绑定当前操作再通知旧请求取消。处理同步回调和迟到结果，避免旧流程覆盖新页面、改用新实例或误取消新请求。
- **改进整合包和组件兼容性。** 支持合法长 Mod 文件名与整合包相对路径，修复长名称缓存不能复用、合法 Fabric API 文件名被拒绝的问题。兼容部分 HMCL 导出、只声明客户端环境的 MRPACK；继续区分必选、可选和不支持客户端的文件。取消先于文件访问和缓存创建，保留路径安全、校验、隔离与原子发布。
- **修正下载与结果细节。** Mod 批量更新限速统一将 MB/s 换算为字节/秒，0 仍为不限速。旧版本纹理包默认另存目录与实例安装一致；普通资源任务的结果显示实际目标文件，取消或失败保留计划路径。
- **完善发布验证。** 完整界面、动画和导航检查使用有上限的 30 分钟期限，搜索验收为 15 分钟，小型控件检查保留 3 分钟；前置、详情、搜索和资源任务等组合场景各自使用有界的 90 秒总期限。避免增长后的套件仍在执行就被旧期限截断，应用的网络及下载超时保持。发布工件绑定同一份源码、内嵌依赖、文档和验证回执。

PCL、HMCL、PCL-CE 的外部配置继续只读，保留已有实例设置。原版与组件安装、CurseForge ZIP / Modrinth MRPACK 导入、社区资源搜索及指定实例安装继续提供。本地 Mod 更新保留备份与禁用状态；共享目录中的操作仍会影响使用该目录的其他实例，本版不自动补装新的 Mod 前置。

## 下载与升级

关闭旧版后直接运行 **`PCL-DB-7.0.0-beta.1.exe`**；也可下载 ZIP，解压后运行其中的 `PCL-DB.exe`。两个入口使用同一份单 EXE，系统需安装 **.NET Framework 4.8**；程序未做数字签名。无需搬迁已有游戏目录，升级后确认所选启动器和目标目录即可。

附件包含单 EXE、便携 ZIP、源码 ZIP、构建清单、`verification.json`、本说明副本与 `SHA256SUMS.txt`。源码可用 Visual Studio 2026 打开，ZIP 另附许可与使用文档；历史发行保持原样。

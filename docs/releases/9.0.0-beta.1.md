# PCL-DB Beta 9.0

Plain Craft Launcher - Download Bridge 的第九个 Beta，标签 `v9.0.0-beta.1`，应用内显示 **Beta 9.0**。本版发布 C# Core 与动画辅助库重构，并继续检查管理、下载、搜索及快速切换的联动；界面和交互仍以 PCL2 为核心，C# 实现参考 PCL-CE。

## 相比 Beta 8.0

- **底层重构正式进入发行版。** Core 迁至 C#，目录查询、下载、组件与整合包安装、本地 Mod 管理等职责进一步拆分。保留 .NET Framework 4.8、VB 界面和测试、原配置格式、程序集名称及资源名称。
- **动画实现逐步整理，保留熟悉的界面。** C# Presentation 库承接曲线、按压/悬停/选中反馈、卡片高度与部分页面时钟；字体、图标、XAML 和原 WPF 动画类型继续保留。页面错峰、返回、透明度和卡片并行动画仍沿用原时序。
- **修复安装页连续切换覆盖。** 动画使能回调或动画属性清理期间接受了新的选择后，旧操作停止后续写入，避免新页面的时钟、位置或输入状态被旧调用覆盖。取消、快速返回与重新进入继续保留当前选择。
- **Mod 更新反馈与文件校验继续完善。** 更新检查缓存按有效期失效并显示检查结果；下载、支持库、旧资源与整合包散列阶段响应取消，已完成的可复用内容保留供重试。发布前校验与短期文件保护减少共享文件冲突。
- **发布前整体回归。** 检查原版与组件安装、CurseForge ZIP / Modrinth MRPACK 导入、社区资源搜索与指定实例安装、版本隔离、本地 Mod 管理及动画。未在其他审计范围确认新 Bug 的部分保留现有实现。

PCL、HMCL、PCL-CE 的外部配置仍只读，已有实例与原生隔离设置继续保留。PCL-DB 提供下载与本地管理，游戏仍使用外部启动器启动。

## 下载与升级

关闭旧版后运行 **`PCL-DB-9.0.0-beta.1.exe`**；或下载同名 ZIP，解压后运行 `PCL-DB.exe`。两者包含相同的单 EXE，需安装 **.NET Framework 4.8**，程序没有数字签名。无需迁移已有游戏目录，升级后确认当前启动器和目标目录即可。组件安装仍可能需要合适的 Java。

附件包含单 EXE、便携 ZIP、源码 ZIP、构建清单、`verification.json`、本说明副本和 `SHA256SUMS.txt`。源码可用 Visual Studio 2026 打开；历史发行与附件保留。

## 验证范围

发行验证绑定确切的干净提交与单 EXE；Core 检查使用与候选嵌入字节一致的库。完整 UI、动画、搜索和冷启动组，以及双 PowerShell 打包回归、用户提供的大整合包样本、仓库外源码归档构建分别记录。上传后重新下载公开附件并核对 SHA-256。具体数量、源码提交与工件摘要见 `verification.json`；各套件存在重叠，不合计为独立用户场景。

安装与网络检查使用临时目录、受控响应或回环服务；WPF 检查包含真实时钟与离屏布局。它们不替代完整游戏启动、全部加载器/Mod 组合、持续的外部平台可用性和人工桌面帧率验收。已知来源、许可及致谢随包提供。

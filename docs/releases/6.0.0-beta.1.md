# PCL-DB Beta 6.0

Plain Craft Launcher - Download Bridge 的第六个 Beta，标签 `v6.0.0-beta.1`，应用内显示 **Beta 6.0**。本版重点完善本地 Mod 管理，以及管理、下载与搜索之间的连续操作体验，界面继续以 PCL2 为核心。

## 相比 Beta 5.0

- **本地 Mod 多选和批量操作。** 增加“下载新 Mod”“全选”和“可更新”筛选，配合行选择色条及底部浮动操作栏，支持批量启用、禁用、删除和更新。全选只作用于当前筛选结果；下载新 Mod 自动带入实例的游戏版本和加载器。
- **按文件内容检查更新。** 从 Modrinth、CurseForge 识别已安装文件，核对项目、游戏版本、加载器、发布时间及摘要。一方来源失败时保留另一方结果，可刷新重试。查询在后台进行，不阻塞本地列表；不会自动替用户更新文件。
- **更新和删除留有备份。** 更新先下载、校验，再检查目标冲突并替换；保留中文文件名前缀及禁用状态。原文件放在实际运行目录的 `.pcl-db-mod-backups` 中，可手动恢复。取消或失败会撤销本批已发布文件；未选择的文件不覆盖，共享目录中的操作会影响使用该目录的实例。
- **修复本地管理的连续操作。** 进入 Mod 页、操作完成和手动刷新时重新读取原生实例配置；处理隔离目录变化、同目录读写、外部读取失败与取消重试。旧请求先退役再通知取消，避免迟到结果或同步回调覆盖新页面。更新提示保留本地诊断，不再打断悬停动画；系统时间回拨时重新检查缓存。
- **改善资源搜索与返回。** 修复详情“全部”筛选、展开卡片和阅读位置恢复；前置解析、详情图标、本地整合包读取与当前页面分别管理请求，快速切换、返回或取消后不会抢回旧页面。数据包存档选择和任务完成后的管理刷新也处理了失效请求与弹窗替换。
- **完善确认和动画交接。** 安装确认、可选文件提示、任务结束与管理页入场之间保持目标和焦点归属；补全准备失败后可重试。新增操作栏沿用 PCL2 的淡入、回弹与退场时序，保留深色模式和减少动画适配。
- **修正打包等待期限。** 全量界面检查增长后，旧的三分钟期限已不足；构建和单 EXE 打包验收现在给予有上限的十分钟等待，避免检查尚未结束就误报超时。

PCL、HMCL、PCL-CE 的外部配置继续只读，已有实例设置保留。原版与组件安装、CurseForge ZIP / Modrinth MRPACK 导入、社区资源指定实例安装及大整合包支持继续提供。更新前建议自行保留重要整合包和存档；Mod 的前置变化仍需检查，本版不自动安装新前置。

## 下载与升级

Windows 用户可直接运行 `PCL-DB-6.0.0-beta.1.exe`，需要 .NET Framework 4.8；也可下载 ZIP，解压后运行其中的 `PCL-DB.exe`。两个入口使用同一份单 EXE，ZIP 另附许可、使用说明和构建清单。已有游戏目录无需搬迁，运行后确认所选启动器与目标目录即可。

附带源码 ZIP、构建清单、`verification.json`、本说明副本与 `SHA256SUMS.txt`。历史版本及工件保持原样。

## 验证范围

发布候选执行 **7,187 项核心检查、2,031 项界面、1,501 项动画、1,169 项搜索和 25 项单文件检查**，并以同一个明确候选进行 PowerShell 7 / Windows PowerShell 5.1 打包验收。源码归档在仓库外独立构建；附件上传后从公开地址重新下载并核对 SHA-256。实际回执与摘要随工件提供，套件计数存在重叠。

验证使用临时实例、原生配置、受控网络及实际 WPF 时钟和离屏布局，也包括大型 ZIP / MRPACK 样本。它们不代替完整游戏启动、所有 Mod 或加载器组合、真实网络可用性和人工桌面帧率验收。项目为独立第三方工具，来源、许可和致谢见随附文档。

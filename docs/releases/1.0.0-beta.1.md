# PCL-DB Beta 1.0

Plain Craft Launcher - Download Bridge 的首个 Beta，版本标签为 `v1.0.0-beta.1`。这是独立的第三方下载补全工具，读取现有 PCL 的游戏目录，将安装结果放回同一个 `.minecraft`；继续使用 PCL 启动游戏。

## 本版内容

- 原版 Minecraft 版本选择、安装及已有同版本原版的校验补全；支持 PCL 游戏目录发现和中文路径。
- Forge、NeoForge、Fabric、Fabric API、OptiFine、OptiFabric、LiteLoader 选择与适用关系检查。
- 自动、官方优先和 BMCLAPI 优先选源；并行下载、校验、续传、已校验文件复用和跨阶段任务并行。
- 参考固定 PCL 源码的页面切换、卡片折叠、滚动、按钮回弹、选中标记及关于页。补齐快速切换、刷新、取消旧按压和动画中断的状态处理。
- 最后修复被祖先裁掉的长列表行仍过早创建的问题，停止在退场旧列表中创建过期行；保留已访问行与重新展开的选择。
- 单 EXE 内置依赖和文档，打包清单强制记录动画验收、Beta 标识和源码提交；打包失败保留旧输出并尝试回滚。

## 下载与使用

日常使用下载 `PCL-DB-1.0.0-beta.1.exe` 即可。需要随附文档时选择同名 ZIP，解压后运行 `PclDownloadBridge/PCL-DB.exe`。两处 EXE 的字节完全相同，系统需安装 **.NET Framework 4.8**；部分模组加载器安装还需要合适的 Java，可在设置中指定。

首次运行进入「设置 → 游戏文件夹」，读取 PCL EXE 对应的目录或手动选择 `.minecraft`。选择版本及组件后开始下载，完成后回到 PCL 刷新版本列表。已有 PCL 配置和存档不会因读取目录而被改写；默认拒绝覆盖同名实例。旧版本的应用偏好仍使用兼容路径。

本版随附独立 EXE、九文件便携 ZIP、构建清单、源码 ZIP、验收摘要及 `SHA256SUMS.txt`。例如：

```powershell
Get-FileHash .\PCL-DB-1.0.0-beta.1.exe -Algorithm SHA256
```

将结果与同一 Release 的 `SHA256SUMS.txt` 对照。清单记录的是构建和内容一致性，不是数字签名。源码 ZIP 可直接打开 `PclDownloadBridge.sln`，VS 2026 调试方式见 `VS2026_DEBUG.md`。

## 验收范围

发布门槛为 Release 零警告/零错误、745 项核心回归、658 项界面、328 项动画、25 项单文件及 54 项打包检查。最终资产还会对照同一份候选报告核对 ZIP、独立 EXE、文档、依赖、Beta 版本与完整提交。

下载/安装回归使用隔离目录、回环 HTTP 和受控安装器；另核对了官方与 BMCLAPI 真实版本列表可用性。动画使用实际 WPF 时钟和离屏布局，不是桌面帧率测试；本轮没有重新下载完整游戏或逐一启动所有加载器组合。外部来源和组件兼容性仍可能随上游变化。

之前的 `v0.49.0-preview` 至 `v0.56.0-preview` 八个预发布版本及其标签撤回，后续以本 Beta 为入口。代码参照、来源致谢和许可说明见随附 `SOURCE_REFERENCES.md`、`THIRD_PARTY_NOTICES.md` 与 `LICENCE`。

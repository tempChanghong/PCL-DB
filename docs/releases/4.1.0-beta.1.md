# PCL-DB Beta 4.1

Beta 4.0 的大整合包导入修复版，标签 `v4.1.0-beta.1`，应用内显示 **Beta 4.1**。

## 修复内容

- 修复大型资源包、音乐包导致 CurseForge ZIP 和 Modrinth MRPACK 报「整合包解压内容超过大小限制」的问题。移除单文件 128 MiB、整包展开总量 2 GiB 的固定容量上限，继续按流读取和提取。
- 同步移除在线归档 2 GiB 及 Modrinth 文件声明 16 GiB 的硬上限，避免本地可读取但搜索结果被过滤、在线下载仍被拦截。
- 保留摘要、声明长度、路径冲突、实例配置、取消重试和安装发布检查。下载页、详情页、外部启动器支持和动画保持 Beta 4.0 的行为。

使用实际「乌托邦探险之旅3.5.2」ZIP / MRPACK 验证，包中的 **218261798 字节**音乐资源包现可读取和提取。两格式分别校验 **2693 / 2691** 个覆盖文件，并验证提取中取消后重试。另有超过 128 MiB 单文件、超过 2 GiB 展开总量及超过 16 GiB 声明的 Core 回归。

## 下载与升级

关闭旧版后运行 `PCL-DB-4.1.0-beta.1.exe`，或解压 ZIP 后运行 `PCL-DB.exe`。保留原设置和游戏目录，重新选择此前失败的整合包即可；不需要重新下载原 ZIP / MRPACK。系统仍需 **.NET Framework 4.8**，程序没有数字签名。

附件共七项：单 EXE、便携 ZIP、对应提交的源码 ZIP、构建清单、验证摘要、发布说明副本及 `SHA256SUMS.txt`。源码归档在仓库外构建验证；上传后再次下载公开附件核对 SHA-256。Beta 4.0 工件保持原样。

## 验证范围

发布前重新执行完整 Core、1059 项界面、1230 项动画、508 项搜索、25 项单文件及两种 PowerShell 的打包验收，实际结果随 verification.json 发布。套件之间存在重叠，不作为独立使用场景数。

真实样本检查覆盖归档读取、覆盖文件流式提取、取消重试及逐文件长度/摘要核对；不代表全部外部依赖已联网安装或游戏已启动。完整安装事务另由隔离集成回归验证。来源、致谢与许可见随附文档。

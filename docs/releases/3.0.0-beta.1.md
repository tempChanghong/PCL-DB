# PCL-DB Beta 3.0

Plain Craft Launcher - Download Bridge 的第三个 Beta，标签为 `v3.0.0-beta.1`，应用内显示 **Beta 3.0**。本版集中改进历史版本下载、整合包目录兼容性，以及与 PCL2 源码对齐的界面和动画。

这是独立的第三方下载补全工具。读取现有 PCL 的 `.minecraft`，完成安装后继续使用 PCL 启动游戏。

## 相比 Beta 2.0

- **修复 CurseForge 版本列表。** 处理可以搜索到项目但无法取得具体版本的问题，改进目录接口兼容、文件身份、分页边界、空结果和失败重试；继续支持 Modrinth 搜索、版本筛选及在线安装。在线归档和本地 CurseForge ZIP / Modrinth MRPACK 仍共用安装流程。
- **调整历史特供版本。** 移除此前的战斗测试版和实验快照，接入逐项核对的远古版本、旧快照及愚人节版本，包括 Classic、Infdev、Alpha、Beta、旧预览版和 Minecraft 2.0 蓝/红/紫三色版。显示 `PCL-DB特供`，按日期进入原有分类；补充源失败不影响普通清单。保留别名与真实下载 ID，处理历史启动配方、支持库及资源索引冲突。
- **统一默认版本隔离。** 移到「设置 → 游戏 → 默认版本隔离」，下载页不再逐个选择。支持跟随 PCL 和其默认隔离策略；补全已有实例时保留原设置，两平台整合包继续使用独立实例目录。加强共享 Mods、旧资源、路径冲突和取消重试处理。
- **下载页面更贴近 PCL。** 详情页使用标题栏返回，版本筛选采用单行胶囊布局；完善项目摘要、分类标签、加载器名称、下载计数和相对更新时间。列表默认字号、标题/图标度量、长版本号省略和侧栏边缘按固定源码调整。
- **细化原版安装与返回动画。** 保留 260 ms 横移，增加可见卡片错峰淡入和回弹、返回退场，开始下载按钮独立弹出与收起。快速切换从当前画面续接，清理旧时钟和首帧闪现；设置、整合包与任务页交接保留组件、名称、视口和请求状态。

## 下载与升级

日常使用下载 **`PCL-DB-3.0.0-beta.1.exe`** 即可；需要随附文档时选择同名 ZIP，解压后运行 `PclDownloadBridge/PCL-DB.exe`。两个入口的 EXE 字节相同。

运行需要 **Windows / .NET Framework 4.8**，部分加载器安装需要合适的 Java，可在设置中指定。先关闭旧版本，再运行新 EXE；既有游戏目录、PCL 配置和本程序偏好继续保留。Beta 1.0 / 2.0 标签与工件保留。

首次使用可在「设置 → 游戏文件夹」读取 PCL 的目录，或手动选择实际使用的 `.minecraft`。完成安装后回到 PCL 刷新版本列表。特供版本只支持原版安装及校验补全，不提供加载器选择。

## 工件与校验

本 Release 附带七个文件：

- `PCL-DB-3.0.0-beta.1.exe`：可直接运行的单 EXE。
- `PCL-DB-3.0.0-beta.1.zip`：EXE、许可、使用文档和构建清单。
- `PCL-DB-3.0.0-beta.1.source.zip`：最终标签对应的源码，可用 VS 2026 打开解决方案。
- `PCL-DB-3.0.0-beta.1.build-manifest.json`：源码、内嵌依赖、文档、载荷及候选验收记录。
- `PCL-DB-3.0.0-beta.1.verification.json`：本次发行的验证摘要。
- `PCL-DB-3.0.0-beta.1.release-notes.md`：本说明的离线副本。
- `SHA256SUMS.txt`：以上六个文件的 SHA-256。

```powershell
Get-FileHash .\PCL-DB-3.0.0-beta.1.exe -Algorithm SHA256
```

将结果与同一 Release 的 `SHA256SUMS.txt` 对照。摘要用于检查完整性，不是数字签名。

## 验证与已知边界

发布前重新执行 Core、界面、动画、搜索回归，并在仓库外的中文冷目录中运行单 EXE 验收；对同一个明确候选执行打包回归和完整工件检查。当前检查数量为 Core **6123**、界面 **911**、动画 **769**、搜索 **320**、单文件 **25** 项；验证工具和打包检查另列于验收摘要。各套件可能覆盖同一行为，不作为互不重复的实际使用场景数。上传后再次下载公开工件并核对摘要。

第三方服务可能限流或停供文件。摘要不符、必需文件缺失或目标路径冲突会停止安装并保留诊断。部分历史候选仍未接入；不会按名称前缀自动开放。自动检查使用隔离目录、回环 HTTP 和实际 WPF 离屏渲染，不能代替全部历史版本、加载器的真实游戏启动或设备帧率验收。

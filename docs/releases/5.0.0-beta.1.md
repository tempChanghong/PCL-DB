# PCL-DB Beta 5.0

Plain Craft Launcher - Download Bridge 的第五个 Beta，标签 `v5.0.0-beta.1`，应用内显示 **Beta 5.0**。本版继续以 PCL2 的界面和交互为核心，加入本地实例与 Mod 管理，并恢复更多社区资源下载入口。

## 相比 Beta 4.1

- **新增「管理」入口。** 查看已安装版本，按名称、游戏版本和加载器搜索；详情显示实际运行目录、隔离状态、识别问题和目录快捷方式。受支持的独立原版可进入已有校验补全流程，保留名称与配置。PCL、HMCL、PCL-CE 共用同一路径时仍分别解释配置。
- **管理本地 Mod。** 读取名称、版本、ID、加载器和包内图标，支持搜索、启用/禁用及从文件安装。列表按 PCL2 对齐文字层级、禁用角标与悬停反馈；使用实例的实际 Mods 目录，共享目录明确提示，同名不同内容及已知身份冲突不覆盖。
- **恢复 Mod、数据包、资源包、光影包搜索。** 支持 CurseForge、Modrinth 的搜索、详情、版本选择、必需前置链接及另存为。也可安装到指定实例：资源包、光影包进入对应目录，数据包需明确选择存档；安装后联动刷新本地管理。前置提供跳转，不自动批量安装。
- **改进资源呈现和设置。** 修复分类切换、版本信息、下载地址及部分来源失败时的结果显示；补齐中文译名、标签和版本范围缩写。本地实例正确区分愚人节、远古和快照版本。新增社区资源来源、另存为命名格式和 Mod 管理样式设置；主题跟随直接采用外部启动器卡片选中的 PCL，滑稽彩支持动态近似，沿用实验性外观权限。
- **修复连续操作和动画交接。** 处理旧按压误触发、空格键提前执行、弹窗退场时 Escape 穿透、旧请求抢焦点，以及动态主题残留旧颜色。保留正常按压回弹、卡片入场与返回动画，并继续适配减少动画设置。
- **提高失败后的恢复能力。** 资源安装弹窗支持扫描失败提示和刷新重试，校验阶段明确显示加载。修复启动目录恢复被切页中断、共享路径误换启动器身份、设置控件与实际值不同步，以及管理页筛选掩盖加载/失败、返回后遗留加载文字等问题。

Beta 4.1 的大整合包容量修复继续保留。下载、校验、取消重试与原子发布沿用已有机制；外部启动器配置只读，已有实例配置保持。

## 下载与升级

关闭旧版后运行 **`PCL-DB-5.0.0-beta.1.exe`**，或解压便携 ZIP 后运行其中的 **`PCL-DB.exe`**。两者使用相同的单 EXE，仍需 **.NET Framework 4.8**，程序没有数字签名。

保留原设置和游戏目录即可升级，不需要搬动 `.minecraft`。这是独立第三方工具，安装后的游戏继续通过所选启动器启动。

附件共七项：单 EXE、便携 ZIP、对应提交的源码 ZIP、构建清单、验证摘要、发布说明副本和 `SHA256SUMS.txt`。历史 Beta 工件保持原样。

## 验证范围

发布候选重新执行完整 Core、**1,273 项界面、1,457 项动画、710 项搜索及 25 项单文件检查**，并使用同一个候选执行 PowerShell 7 / Windows PowerShell 5.1 打包验收。源码归档在仓库外独立构建，公开附件上传后再次下载核对 SHA-256；实际回执随 `verification.json` 提供。套件存在重叠，计数不代表互不重复的使用场景。

验证包括隔离目录、回环下载、实际 WPF 时钟和离屏布局，以及实际 ZIP / MRPACK 样本的读取、提取、取消与重试。它们不代替完整游戏启动、全部加载器兼容性、真实网络服务可用性或桌面帧率验收。来源、致谢和许可见随附文档。

# PCL-DB Beta 2.0

Plain Craft Launcher - Download Bridge 的第二个 Beta，标签为 `v2.0.0-beta.1`，应用内显示 **Beta 2.0**。本版补齐整合包搜索与安装，并继续完善隔离、下载可靠性和 PCL 风格动画。

这是独立的第三方下载补全工具。读取现有 PCL 的 `.minecraft`，安装后继续使用 PCL 启动游戏。

## 相比 Beta 1.0

- **整合包搜索与在线安装**：在下载侧栏选择「整合包」，按名称、Minecraft 版本、来源和类型筛选 CurseForge / Modrinth 内容；查看项目、选择具体发行版本、确认实例名称后下载安装。补齐分页、单源失败重试、版本信息和快速切换的状态处理。
- **本地整合包导入**：支持 CurseForge ZIP 和 Modrinth MRPACK，可选择文件或拖入窗口。按清单解析游戏与加载器版本，处理可选文件、覆盖目录和校验；整合包使用独立实例目录。在线下载与本地导入共用安装流程。
- **版本隔离**：原版安装页提供「跟随 PCL／开启隔离／关闭隔离」。补全已有实例时保留原设置；修正旧资源目录、共享 Mods、同名文件冲突和取消重试的处理。
- **补充版本**：新增战斗测试版及部分实验快照，单独分类并处理 ID 别名。补充清单独立加载，失败不妨碍正常版本下载。
- **动画与界面**：继续对照 PCL 源码完善标题栏按钮、滚动条、单选框、加载图形和搜索详情切换。蓝色与深色模式、快速切页、隐藏卸载和关闭动画时的状态同步一并修正。
- **下载与安装修复**：加强异常响应、资源摘要、加载器元数据和共享运行库校验；修复在线归档从下载转入解析时的内容替换空隙。保留已有实例、用户设置及已校验缓存，失败或取消后可重试。

## 下载与升级

日常使用下载 **`PCL-DB-2.0.0-beta.1.exe`** 即可；需要随附文档时选择同名 ZIP，解压后运行 `PclDownloadBridge/PCL-DB.exe`。两个入口的 EXE 字节相同。

运行需要 **Windows / .NET Framework 4.8**，部分加载器安装需要合适的 Java，可在设置中指定。关闭旧版本后运行新 EXE，无需重新配置已经保存的游戏目录；现有偏好、PCL 设置和游戏文件继续保留。

首次使用可在「设置 → 游戏文件夹」读取 PCL 的目录或手动选择 `.minecraft`。整合包页的「安装已有整合包」进入本地导入；完成安装后回到 PCL 刷新版本列表。

## 工件与校验

本 Release 附带七个文件：

- `PCL-DB-2.0.0-beta.1.exe`：可直接运行的单 EXE。
- `PCL-DB-2.0.0-beta.1.zip`：EXE、许可、使用文档和构建清单。
- `PCL-DB-2.0.0-beta.1.source.zip`：对应标签的源码，可用 VS 2026 打开解决方案。
- `PCL-DB-2.0.0-beta.1.build-manifest.json`：源码、内嵌依赖、文档、载荷及候选验收记录。
- `PCL-DB-2.0.0-beta.1.verification.json`：本次发行的验证摘要。
- `PCL-DB-2.0.0-beta.1.release-notes.md`：本说明的离线副本。
- `SHA256SUMS.txt`：以上六个文件的 SHA-256。

```powershell
Get-FileHash .\PCL-DB-2.0.0-beta.1.exe -Algorithm SHA256
```

将结果与同一 Release 的 `SHA256SUMS.txt` 对照。摘要用于核对文件完整性，不是数字签名。Beta 1.0 的历史标签及工件保留。

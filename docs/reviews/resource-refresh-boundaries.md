## 文件冲突与完整管理联动

扩展原真实回环获取链路：

1. 临时 PCL 格式实例获取有效 Fabric Mod 归档，在发布前通过 UI 取消：文件未发布，管理缓存失效。
2. 夹具放入不同内容的同名文件再重试：任务失败、明确提示已有文件保留、文件字节不变，管理读取成功标志失效，没有额外网络请求。
3. 由夹具明确移除冲突文件后再重试：使用已校验缓存原子发布，返回管理后读到新 Mod，没有安装到隔离实例。

三次尝试共 1 次 HTTP 请求。搜索元数据与实例由夹具提供；网络获取、缓存、原生文件发布和本地 Mod 识别为生产实现。程序不自动清除冲突，测试中的文件移除与临时实例元数据变更均属于夹具操作；外部配置字节保持。

既有专项仍覆盖存档 marker 变化、刷新后明确重选、快速切换、同目录不同启动器绑定、旧管理读取、共享目录及取消重试。本轮不改数据包存档身份检查或资源包/光影目录映射。

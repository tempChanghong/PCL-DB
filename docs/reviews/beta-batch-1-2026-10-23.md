# 远古版本补充：首批 Beta 1.9 预览版

本轮接入 `b1.9-pre1` 至 `b1.9-pre5`，与既有 `b1.9-pre6` 连成完整的六项预览版。累计支持 80 项补充版本：67 项旧快照、10 项远古补充和 3 项 2.0 三色版。归档历史候选累计接入 77/171 项，剩余 94 项（27 项字段完整、67 项缺少库／索引声明）。这不等于所有历史版本均已支持，也不提供游戏启动或世界存档验收结论。

研究分组保存在忽略目录 `artifacts/beta-batch-1/candidate-groups.json`。下一批的 `b1.8-pre1-2` 对应上游路径 `b1_8-pre1`，不能机械替换前缀后保留 `-2`；`b1.8-pre1-1` 又使用原始点号路径，必须逐项核对。

## 固定 PCL 源码对照

参考提交 `5ef81e490ae46b1100d61e33d0183094c7a80ca8`，五份本地参考与对应 Git 对象在标准化行尾后核对：

- `ModDownload.vb / DlClientListBmclapiMain`：附加清单合并后进入现有下载流程，不另建安装器。
- `ModDownloadLib.vb / McDownloadClientLoader`：库与资源以非阻塞阶段并行，记录原始 `clientVersion`；复用现有选源、共享预算和文件校验。
- `ModDownloadLib.vb / McDownloadListItem`、`PageDownloadInstall.xaml.vb / ShowMinecraftVersionList`：old_beta 属于远古类别，使用圆石图标、42 DIP 行与日期排序。本批进入既有“远古版本补充”卡片，不重建已展开普通行，不进入最新推荐，也不改动页面动画。
- `ModMinecraft.vb / McLibListGetWithJson`、`McAssetsListGet`：对照库规则与资源映射；`map_to_resources` 指向有效隔离目录的 `resources`，与根目录 `assets/virtual/legacy` 区分。
- `ModLaunch.vb / McLaunchArgumentsReplace`：`${game_directory}` 跟随有效隔离目录，`${game_assets}` 保留根目录 legacy 资源语义；保留已有 JSON、用户参数与隔离设置。

./tests/PclDownloadBridge.Tests/bin/Release/net48/PclDownloadBridge.Tests.exe --live-supplemental './artifacts/beta-batch-1/live-metadata'
./build.ps1

验收覆盖只读注册表与原始夹具集合一致、路径 ID 不冒充别名、错误分类／pending 拒绝、RC1 特例、补充失败隔离及 UI 分类／图标。共享资源冲突回归扩展至全部 67 项快照和 7 项 Beta：隔离安装保留根目录不同内容；关闭隔离时拒绝覆盖和发布；由测试明确纠正冲突后才能同名重试。该受控测试使用真实固定摘要的 wrapper 与合成客户端／资源，不算联网安装证据。

联网验收在新目录逐项安装本批五个真实版本，不读取外部游戏目录作复用源；后续版本仅共享本轮已校验文件。逐项核对客户端、库及资源摘要、资源落点、发布前取消与同名重试、UTF-16 JSON／INI 原字节保留、已有隔离设置与用户参数，以及损坏客户端补全。全量在线清单入口检查 80 项补充版本及普通 `rd-132211`，不将这一检查称为 80 项全部重新安装。

源码清单、固定 PCL 核对、定向进程、联网安装、全量元数据、构建与最终成功回执保存在忽略目录 `artifacts/beta-batch-1/`。源码清单与二进制摘要绑定本轮验证；最终数量和成功状态以 `validation.json`、`live-binding.json` 为准。在线元数据的重新序列化副本只用于诊断，不替代原始夹具或上游摘要。

本轮不启动游戏，不提供 PCL GUI、Java 兼容性、游戏内资源或创建／保存／重进世界的人工验收结论；不打包、不发版。

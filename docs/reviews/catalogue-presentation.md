# 管理分类与资源中文呈现

基线 `b5564bf9cfe6aec3627324e326529869d6360fa6`。上一轮资源加载/内置图标/主题来源已验证并提交，本轮处理用户新截图中的管理分类及资源中文显示。

## 版本分类

原本地目录读取器未保存 Minecraft 分类；管理图标只区分整合包、Fabric 和其他组件，因此愚人节与远古原版都显示草方块。现在按固定 PCL 的 McVersion 规则识别已知愚人节名称、JSON 类型及 UTC+2 的四月一日快照，识别 rd/Indev/Infdev/Classic/Alpha/Beta 等远古版本。3D Shareware、1.RV-Pre1 和无限快照等非标准名称也可作为真实游戏身份读取。

版本继承保留原版分支的分类元数据，避免组件 JSON 的 release 类型覆盖原版快照或远古身份；HMCL patches 也在合并组件前保留 game 分支。文件夹显示名不作为愚人节身份依据。保留已有组件、整合包图标优先级，原版愚人节用 GoldBlock、远古用 CobbleStone、普通快照用 CommandBlock。详情和搜索使用同一分类。不写外部配置或 PCL 的 State/Logo 缓存，不修改版本隔离和补全许可条件。

## 中文与标签

按固定 PCL WikiEntry.cs 的 @ 平台关系和星号简写，原样嵌入 946,775 字节的 WikiEntries.txt；数据库只在首次需要时读入，名称显示不增加联网等待。按平台和 Slug 精确关联 Mod/数据包中文名，不按相似名称或跨平台 ID 猜测。中文标题、较小的灰色英文副标题沿用同一资源行，搜索行、详情头部与返回标题一致；项目原名、平台 ID、Kind、下载文件和版本身份不改。没有译名继续用原文；简介不做机器翻译。本轮不新增 PCL 的中文模糊搜索算法。

补齐固定 ResourceProject 中 Mod、数据包、资源包和光影的分类词典，复用现有灰色圆角标签及明暗资源。共享的分类标识按资源类型解读，未知或无效标签忽略。

## 版本缩写与交互

参照 ToResourceItem 与 ModDownload.AllDrops，仅将成功读取的普通正式版清单作为全局版本族顺序；不把 UVMC 补充条目插入正式版序列，不为资源显示另取一次清单。相邻族生成 1.16+ 或有界范围，断档仍显示为独立版本，例如 1.16+, 1.12；缺少全局清单继续逐项展示。主流加载器组合按 PCL 的时代规则省略冗余，完整加载器及游戏版本始终留在提示中，实际安装仍检验所选文件的明确支持范围。

保留统计行原列权重；优先给兼容说明自然宽度，最多占行宽的 42%，其余统计仍受边界约束。维持 64 DIP 行高、17/18/16 DIP 三条文字带、现有焦点/点击与悬停动画。显示转换不启动请求或撤销任务，快速切换和取消仍由原所有权机制管理。

# 跟随 PCL 当前主题

基线 `3390f0928f8e340926af93eefeee516897be86f0`（Beta 3.0）。本轮增加只读主题跟随，验证后本地 Commit，暂不打包、推送或发版。

## 源码依据与边界

固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 `Settings.vb`、`ModBase.vb`、`PageSetupUI.xaml` 和 `ModSecret.vb` 已按 Git 对象读取，规范化副本与 SHA-256 保存在 `artifacts/follow-pcl-theme/source/`、`source.json`。当前主题来自 PCL 程序旁的 `PCL/Setup.ini` 的普通键 `UiLauncherTheme`，不是插件接口。配置为冒号分隔，重复键采用最后一条，缺少主题键的有效配置采用默认 0。

公开源码没有保留非默认主题的完整调色/解锁实现。当前支持龙猫蓝及本程序已有的五项近似预设（甜柠青、小草绿、菠萝黄、橡木棕、玄素黑）；非公开外观仍受 PCL-DB 原有开发者解锁限制，不迁移 PCL 解锁记录。其他隐藏配色、动态/自定义配色、未知 ID 均显示原因并回退本机外观，不按 ID 猜测颜色或动效相位。PCL 只在内存中变化而尚未保存的状态无法感知。

## 行为

- 设置页增加开关、配置路径、选择/刷新按钮及状态说明。用户明确选择一份 PCL EXE 或它的 `Setup.ini`；不按进程、最近修改时间或游戏目录猜测。绑定独立保存，切换游戏目录不应切换主题来源。
- 只使用 `FileAccess.Read` 与共享读/写/删除句柄，限制 1 MiB，接受 UTF-8 及 BOM 编码；空文件、坏编码、不完整主题键、非法编号、占用或缺失均作为可恢复失败。读后不改源文件、注册表、解锁状态或属性。
- 后台每 500 ms 采样，连续两次完整内容指纹一致后发布主题状态；只改无关设置不会重刷调色板。可看到原文件覆写、原子替换、删除/重建；长期失败或不支持时回退本机外观，恢复后自动跟随。
- 切换来源/关闭开关递增代次，旧结果不会覆盖新绑定；每代至多一次读取、整体至多两次在途读取，避免快速切换累积后台线程。关闭窗口停止计时器，晚到结果丢弃，处理 Dispatcher 正在关闭的竞态。网络文件系统若阻塞，读取结束时间由 Windows 决定，UI 使用本机回退且不等待该读取。
- 外部主题作为临时显示层，不覆盖本机手选主题、自定义参数、深色模式、透明度及背景偏好。关闭跟随恢复本机选择；原有未知配置字段和其他下载设置在保存时保留。普通确定性预览不读取真实外部配置。
- 实际换色仍经过现有外观入口，不重建下载列表、重开请求或重播切页；检查保留页面/卡片时钟、组件对象、正文及实例名称。相同有效调色板不重复刷新组件。

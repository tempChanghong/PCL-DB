# 输入弹窗的返回焦点

基线 `ca0badcdb842de80b743a4609efc35028c7f0dab`。以固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 `Controls/MyMsg/MyMsgInput.xaml.vb`、`MyScrollViewer.vb` 和 `MyPageRight.vb` 为核心依据；不引入新的 CE 布局或交互框架。

## 问题与范围

原实现关闭弹窗时两次调用通用下载页焦点逻辑，详情页默认目标是顶部网站按钮，没有记录实际调用版本行。隐藏 WPF 窗口中在 370 项通过后复现：弹窗已隐藏，逻辑焦点仍为 OnlinePackName，未返回可见版本行；当时视口仍为 420 DIP。这是逻辑焦点复现，不能据此宣称已经测到前台窗口滚动跳转。

原始失败回执和状态另存为 `focus-reproduction.json`、`focus-reproduction.state.json`。源码、Git blob 与 SHA-256 保存在 `artifacts/prompt-focus/source/`。新增返回机制属于本工具的异步交互适配，不宣称固定 PCL 已包含同样的 API。

## 修正

- 版本行显式传递调用控件，避免鼠标/辅助功能操作后仍使用旧网站按钮的键盘焦点。其余弹窗从当前活动页面捕获原焦点，使用弱引用保存控件。
- 关闭后优先恢复仍属于原页面、可交互且完整位于视口内的调用控件；移除、折叠或移出视口后回退到滚动容器。聚焦时保留当前夹紧后的滚动位置，不写回弹窗开启前的历史偏移。
- 沿用现有根页面/下载页焦点队列。入场期间的新焦点优先；替换弹窗、页面/项目切换、导航往返和新任务接管会使旧请求失效。设置页的可选文件提示返回设置控件，关闭窗口时不执行迟到恢复。
- 移除 CompleteOnlinePrompt 中提前进行的通用焦点请求，由弹窗真正退出后统一恢复。新页面已取得焦点时保留其所有权，没有可恢复目标时才使用当前页面默认焦点。

保持 PCL 弹窗的输入验证、旋转/位移/淡入淡出及退出时钟所有权，保持项目卡片、目录绑定、查询、版本隔离和下载安装事务。没有改变确认结果、取消语义或实际安装代码；可选参数只携带 UI 返回目标。

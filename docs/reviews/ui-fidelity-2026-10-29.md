# UI 还原度：本地 Mod 卡片与下拉菜单

基线：`b7395e01f38e5aab02c5ac79b882427271716a41`。本批修改界面度量与控件透明度，不进入第三轮 Core 重构，不打包发版。

## 三方对照与问题归属

迁移前 VB.NET 版为 `v8.0.0-beta.1` 对应的 `872220b0f7a8303530c5cddaa74af5aafe04c499`。与本批基线相比，App 仅 Core 项目引用和一处搜索验证采样不同；业务 XAML、控件与动画源码相同。所读版本分类、名称、统计和排序链未发现确定的迁移显示回归。因此本批修复的是旧版已存在的还原缺口，不把它们称为 C# 迁移新造成的问题。

UI 以固定 PCL2 `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 为主，PCL-CE `915ac29795efbdf6373417389e181e1504117048` 只参考响应式安排。旧 VB 源与对照摘要见 `artifacts/ui-fidelity-review/old-vb-comparison-source/manifest.json`、`old-vb-comparison.md`；四份上游界面原始字节另存于 `fixed-ui-source/manifest.json`。

## 本地 Mod 页

PCL PageInstanceMod.xaml 指定操作区 35 DIP 高、上下各 15；筛选区原点 (15,13)、高 28；列表边距 (20,48,18,22)，筛选顺序为全部、启用、禁用、可更新。原工具把筛选和列表放在同一 StackPanel 内共用边距，按钮下方又额外留 6 DIP。

| 度量 | 原布局 | 本批目标／PCL 依据 |
| --- | --- | --- |
| 无反馈时操作卡片高度 | 71 | 65 |
| 首操作按钮距卡片顶部 | 15 | 15，保持 |
| 筛选容器原点 | (15,12) | (15,13) |
| 首行原点 | (15,50) | (20,48) |
| 列表右／下边距 | 15／15 | 18／22 |
| 筛选顺序 | 全部、可更新、启用、禁用 | 全部、启用、禁用、可更新 |

列表改为共同 Grid 内的独立筛选层和内容层，保留原控件和行身份。操作区仍支持窄窗口换行：参考 CE PageInstanceCompResource.xaml 的外层顶部 8 与按钮顶部 7，使正常首行保持 PCL 的顶部 15、卡片高 65，换行保留 7 DIP 间隔。刷新、取消及反馈行继续原有显隐和增长逻辑，不改文件操作、选择集合或行动画。

## 下拉菜单不透明度

PCL MyComboBox.vb:109 与 CE MyComboBox.cs:192-193 在打开时将 PanPopup.Opacity 同步为 FrmMain.Opacity。原工具只刷新颜色，窗口设为 70% 时弹窗仍是 100%。本批使用实际所属 Window 的单个实时绑定，属于多窗口与预览边界适配，并非照搬全局 FrmMain：窗口透明度变化时同步，快速重开不叠加绑定；换模板、换窗口和卸载只回收自建绑定并保留退役弹窗当前透明度。调用方显式绑定／动画及无 Window 的预览保留自己的值，不触碰主题、选择或悬浮时钟。

## 验证与限度

本地 Mod 几何／明暗／窄宽／筛选／换行反馈新增 55 项，原按钮行内 Y=0 的检查改验实际卡片 Y=15，没有放宽还原目标。弹窗新增 12 项，覆盖 70%→40%→100%、重开、重模板、第二窗口、卸载、外部绑定／动画和无窗口预览。

首轮候选保留一处真实失败：调用方已分配动画、首 tick 前 IsAnimated 仍为 False，而 HasAnimatedProperties 已为 True；打开菜单后错误附加了窗口绑定。隔离诊断保留四阶段采样，随后增加首帧保护与真实前提断言，不删除或放宽原动画断言。

私有隔离探针使用相同检查源码及冻结 Core／JSON，仅替换上述两份旧／新运行时界面文件，保留旧布局的度量、截图和失败标签；探针入口不进入正式程序。最终单 EXE 按更新后的严格数量验证，源码、实际内嵌依赖、文档与提交树绑定到 `artifacts/ui-fidelity-review/validation.json`。Core 二进制若逐字节相同，明确复用上一批已完成的 7687 项完整 VB 与 7305 项旧宿主结果，不冒称重跑。

这是源码规格对照与受控 WPF 场景验证，不是三个发行应用的全页面逐像素比对，也不构成真实桌面帧率或在线安装验收。标题、副标题和资源统计列的其它旧还原差异保留为后续候选，不在本批扩大重做。

# 启动器绑定恢复与目标选择

基线 d367b45ff7604683b5074bbfa7e6ccf45759cc39。本批沿配置恢复审查修复异常隔离与未知字段保存问题，保留 VB WPF、VB 测试、.NET Framework 4.8、程序集与公开／Friend 接口。

## 复现与分类

同一个公开接口探针分别加载当前 C# Core 与原 Beta 8 VB Core：

| 输入 | 两个旧版本的结果 | 修复后 |
| --- | --- | --- |
| externalLaunchers 缺少 format | NullReferenceException | 原对象只读保护，不猜测格式或改写 |
| selectedRows 某类值为对象／数组 | 整组恢复抛出 ArgumentException | 仅该类回退到首个有效绑定，保留其他类选择 |
| 已保存目标的一半为对象／数组 | 恢复中断 | 清空不可信目标组合，保留有效绑定并提示重选 |
| selectedRows 中含未知启动器键 | 保存时丢失 | 与原快照合并，保留未知键及其值 |

这些问题在原 VB 版本已经存在，不将其描述为本次 C# 迁移引入。原始探针结果保留在 baseline.json、original-vb.json。完整回归另覆盖整个选择表类型错误、旧 gameRoot／pclBase 类型错误、未知版本和字符串格式等。

## 修复范围

- Core 的 LauncherBindingsState 增加私有文本读取边界，保留原有可转换标量行为，仅隔离类型转换错误。格式判断改为显式、空值安全的 C# 条件；未知格式继续返回原始对象的副本。
- 有效绑定逐项恢复，坏选择仅影响所属类别。目标 ID 和根目录共同恢复，无法信任的一半不会与其他来源拼接；旧 PCL 位置类型错误也清空活动目标。
- ToJson 从原始 selectedRows 对象继续合并已知选择，保留未知启动器的字符串、对象和空值。返回 JSON 与内部快照不共享可变节点，调用方输入保持不变。
- 启动界面发现恢复警告且没有可信目标时，不自动挑选列表第一项；已有有效目标仍按原逻辑恢复。读取代次与过期结果门控不改，迟到的坏目标恢复不能覆盖新的有效恢复。

不修改外部启动器配置，不改变安装隔离、共享目录、文件发布、下载取消或动画参数。已冻结的安装目标仍独立于之后的编辑操作。

## 源码依据

PCL2 固定 5ef81e490ae46b1100d61e33d0183094c7a80ca8 的 Settings.vb 设置项读取、转换失败和默认值处理为主要依据；C# 重点参考 CE 915ac29795efbdf6373417389e181e1504117048 的 ConfigItem.GetValue、ConfigValueCache 与 FileConfigStorage:106–135 的逐项失败隔离。CE 的坏项删除和同步写入不移入本工具。

HMCL 固定 63207affc6a73127cea19e64272a0401fde4b7a4 的 GameDirectoryManager／LauncherSettings 用于核对目录身份与选中 ID 的关系。本工具的绑定 JSON 格式和未知字段保护是自身协议，不声称上游存在同名功能。

旧 VB 源码固定为 Beta 8 的 872220b0f7a8303530c5cddaa74af5aafe04c499；连同当前调用链和策略共 17 份 Git 原字节见 artifacts/launcher-binding-recovery/source/manifest.json。

## 安装机制

| 类型 | 实际目标 | 限制与已有文件 |
| --- | --- | --- |
| Mod | 原生运行目录 `/mods` | 版本/已识别加载器匹配；复用本地 Mod 归档检查；禁用别名、同名不同内容和已知重复 Mod ID 不覆盖 |
| 资源包 | 原生运行目录 `/resourcepacks` | 1.5 及更早的匹配版本使用 `/texturepacks`；不修改 options |
| 光影 | 原生运行目录 `/shaderpacks` | 只安装文件，需游戏具备相应组件并自行启用 |
| 数据包 | 原生运行目录 `/saves/<所选存档>/datapacks` | 必须明确选择存档，切换实例清空旧选择；不写 level.dat |

- 安装前重新读取实例，冻结启动器绑定、配置摘要、元数据、实际目录、资源摘要和存档身份。下载沿用已校验缓存；下载结束复查配置与目录物理身份，既有资源目录被替换、存档目录身份或 `level.dat` 变化时停止并要求重选。
- 发布持有原生目录链、源文件和目标文件句柄。Mod 与原本本地管理共用物理 Mods 目录互斥及状态别名检查；其他资源共用运行目录互斥和根安装锁，避免与实例安装交错。不同启动器指向同一共享目录时也不能绕过互斥。
- 相同内容复用，其他同名内容保留并报错；不同文件名但已知 Mod ID 重复时也停止，不自动替换旧版本。复制、落盘、校验完成后才原子改名；取消或失败只删除自己持有的新文件，其他任务抢先生成的文件保留。
- 只允许创建所选资源子目录；不创建缺失运行目录、存档或隔离配置。失败可能留下一个本次新建的空资源目录，不按路径删除不明所有者的目录。辅助安装锁/缓存属于本工具文件，不是外部配置更改。
- 返回任务前后的详情、搜索与类别保留；禁止后台页面或陈旧行启动第二次下载。实例/世界读取均有取消与所有权检查，迟到结果不能覆盖新选择。弹窗快速关闭/重开也保留当前动画与输入门控。
- 成功、取消或失败后保守失效本地管理缓存；同一实际目录的本地 Mod 列表失效，返回管理后重新读取。暂不新增资源包、光影包和数据包的本地启停列表。

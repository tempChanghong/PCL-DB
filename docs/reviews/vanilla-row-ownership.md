# 原版版本行与折叠退场的归属

基线 `817b9c381fe35cf89cf7316d5f3c7d593e267895`，工作分支 `main`。本轮以固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 MyCard、MyPageRight 和 PageDownloadInstall 为依据，没有引入新的 CE 布局。

## 复现与修正

PCL 卡片在折叠动画完成前保留内容可见。组件行和整合包行已经检查当前卡片/body，但原版行直接调用 SelectVersion。实际 WPF 分类卡片折叠 10 ms 时发送原版行点击，旧实现记录 `folded=true`、`view=Install`、`selectedOldEntry=true`，复现折叠后仍进入安装页。原始状态在 `reproduction.state.json`，失败回执在 `reproduction.json`。

- 原版行点击前确认当前为可交互的原版列表、行属于仍展开的当前卡片/body、卡片没有退役内容，以及版本元数据对象仍在当前清单中。清单替换后的旧卡片、同 ID 的旧元数据和设置/安装等页面中的旧行均无权发起新选择。
- 拒绝发生在修改键盘返回对象和调用 SelectVersion 之前，保留当前版本名、自定义名称、组件代次、待恢复焦点及安装任务。
- 不以加载中状态或加载代次作废全部行：后台刷新尚未替换清单时仍可使用现有列表；补充版本增量插入保留的原有行也可继续选择。

PCL PageDownloadInstall 的延迟构建、Tag 与 Lambda 点击转发、MyCard 的退出保留和 MyPageRight 的退场输入门控为参考。本工具额外检查异步清单的对象与容器归属，不宣称固定 PCL 存在同名接口。XAML、字体、图标、折叠/页面动画、直接内部选择接口、目录/隔离与下载安装内核保持。

## 验证

新增 15 项真实原版页检查，包含折叠时钟尚在运行的点击、八类页面/输入边界、清单替换、相同 ID 的新对象、当前新行、已有安装表单、有缓存的后台刷新、补充版本插入后原行复用。使用实际鼠标/键盘路由和排队激活入口，核对名称、组件、返回焦点及任务身份。

全量回归中的旧版本分类夹具会在安装页直接激活隐藏行；按新的有效交互约束，改为显式返回原版列表并结束入场，再验证点击。首次全量运行另触发刷新夹具 10 秒时限；该次业务结果文件全部为通过，下一次运行未重现超时。保留 `all-deadline.json`，不扩大时限或将失败回执当成通过。

策略 `PCL-DB-checks/2026-10-24.41`：UI 1059、动画 1154、搜索 448；新用例同时进入 UI 和动画套件，不能相加为独立用例数。固定源码/资源、验证契约和进程工具另查。最终通过数量、源码摘要、EXE 与 Commit 绑定以 `artifacts/vanilla-row-ownership/validation.json`、`committed-validation.json` 为准，固定源的 Git blob / SHA-256 在 `source/manifest.json`。

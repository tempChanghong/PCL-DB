# 静态纵向滚动与动画模式交接

基线 `5e8bc7352a2c9eb798c14d0ee3e41d6cacf733e8`，工作分支 `main`。核心依据固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 MyScrollViewer、PageDownloadInstall 和 PageDownloadCompDetail；没有采用新的 PCL-CE 布局或逻辑。

## 复现与修正

关闭平滑滚动或动画时，旧分支每次清理状态并基于 VerticalOffset 计算目标。WPF 原生命令尚未确认，连续输入读取相同起点，最后一条覆盖前面的位移。隐藏 WPF 中从 100 连续三次 -120，预期 460，旧实现实际 220。失败回执 `reproduction.json`、原始位置 `reproduction.state.json` 保留在本轮 artifacts。

- 静态分支复用待确认目标与有界原生请求记录，逐输入夹紧，ScrollChanged 区分自身确认与外部滚动；最终确认后清理目标。无需为每个静态输入强制同步布局。
- 禁用、门控、隐藏、卸载和指针/键盘/触摸接管时，既撤销时钟，也以当前显示位置替换排队请求。视口尺寸变化同样清理。正常时钟完成仍保留最终已接受位移。
- 从静态恢复动画时先确认已接受的原生位移，并在布局后复核交互所有权；切到静态时撤销旧动画，后续输入从当前显示位置累积。过期时钟不能影响新状态。

PCL MyScrollViewer 的 RealOffset 增量和原生同步是参考依据；关闭动画后的回退为本项目补充，不宣称固定 PCL 已有同样实现。正常 300 ms 六次方滚动曲线、卡片/页面入退场、嵌套路由、XAML、配色、版本文件与下载安装事务均保持。

## 搜索与加载

读取用户的 18.67 秒录屏，按秒采样并结合源码追踪首次进入。原界面先放置“输入名称或选择条件后搜索”，等分类动画结束再自动查询，随后再等加载延迟；用户会看到不必要的手动搜索提示。现在在父级页面内容更新期间就接受初次请求，直接显示加载。现有父级动画收集最终控件，不再另开子级入场；最小停留仍从真实入场完成计算，正常手动搜索保留原等待策略，取消和隐藏会清理排队观察。

原混合搜索使用 WhenAll，快来源也被慢来源挡住。新增只读的阶段性预览：一源返回即可显示、点击并进入详情，未完成来源显示蓝色加载提示。所有来源结束后才按原相关性、下载量和项目键生成最终顺序并推进独立游标。预览不提前提交游标，取消可从同一会话安全重试；晚到结果只更新搜索缓存，不能覆盖当前详情，已阅读预览时不因最后一源完成而强制滚回顶部。

本轮开始时，CurseForge 数据包/光影接口实测均可返回 40 条，未复现永久分类缺失；视频长等待与原十五秒单请求超时路径一致。固定 PCL 的 DlModRequest 会重复十秒 MCIM 请求，本工具据此对镜像的超时、传输失败与临时 HTTP 错误增加一次有界重试；永久 HTTP 错误和无效元数据不循环重试。最终失败明确标出 CurseForge，保留其他来源结果，不把上游服务问题伪装成成功。

修改后实际混合搜索：数据包约 783ms 首批 40 条、1279ms 完成；光影约 679ms 首批 40 条、4180ms 完成。两次最终均收集到两来源各 40 条，错误为空，按原规则展示第一页。以上是单次联网观测，不能承诺所有网络或时段都达到同样耗时。

## 本地图标与实例详情

原本地 Mod 行始终设置 NoIcon，与文件由谁下载无关。新增从 Fabric、Quilt、Forge/NeoForge TOML、旧 Forge 和 LiteLoader 的元数据读取图片声明，支持 Fabric 尺寸字典；只在归档内读 PNG/JPEG，按内容识别被错误命名为 png 的 JPEG。图片受单文件一 MiB、像素尺寸及单次扫描总图片内存约束；路径无效、图片缺失或损坏只回退图标，不改变 Mod 识别、启停、导入或摘要。归档与配置不写入、不解压执行；图像在内存中解码并冻结。

对用户 Utopian Journey 3.5.2 的 453 个 JAR 做只读核查，453 个均识别，382 个取得可用内置图片；逐文件修改时间保持。剩余文件没有提供可用内置图标时继续使用占位。固定 PCL2 的 MyLocalModItem 使用已识别项目的在线图标；本轮以 CE 的内置图片读取作补充，没有新增批量联网指纹/项目信息识别。因此这里不声称所有缺失图片都已恢复，也不猜选归档中的其他纹理。

实例详情原图标被填充到狭长空间。现在仅该高行简介使用 Uniform 等比显示，其他 PCL 列表默认值不变；本地 Mod 图片也保持比例和禁用角标。

## 跟随 PCL 主题

“跟随 PCL 当前主题”直接绑定外部启动器卡片中明确选择的 PCL 工作目录/配置。切换、增添或恢复该选择会重绑只读监测并撤销旧回包，不需要再次选择 PCL。重复选择同一路径不重启监测。独立路径输入、选择和刷新不再显示，状态仍可查看，配置路径留在提示中。

没有 PCL 绑定时保留旧版本保存的明确来源；一旦存在外部 PCL 绑定，使用该卡片的选择。明确选择失效时使用本地外观，不跳回另一份旧配置；关闭跟随后停止监测并恢复本地主题控件。未知配色、实验外观权限、明暗模式、配置短暂写入/读取失败与动画沿用原规则，始终不修改外部配置。

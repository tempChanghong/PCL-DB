# 管理目录操作的重绘与交接

基线 e95be0d41d59404f65b879c9651ee824359de773。本轮检查管理入口中的文件夹快捷操作；保留 VB WPF、C# Core、VB 测试、.NET Framework 4.8、现有配置及资源名称。

## 问题与复现

OpenManagedFolder 已在两个异步读取后检查任务身份，但完成读取并不代表仍可执行最后的系统操作。刷新列表或详情时，WPF 通知可同步触发返回；系统打开回调也可接受新的文件夹点击。旧操作在这些边界没有复核身份，仍打开原目录，或者把新请求的“正在读取文件夹…”清空。

新增用例通过真实按钮入口发起读取，在 ManagementSummary／ManagedRunPath 的属性通知中调用原有返回处理器；另一组在注入的系统打开回调中发起第二次真实按钮请求，再受控释放新读取的成功或 I/O 失败。观察目标、请求身份、状态文字、任务代次与返回动画时钟。完整应用入口的原实现失败回执保存在 artifacts/management-folder-publication/baseline-navigation；每次输出均使用新的目录。

这证明受控重入路径存在，不能推算真实机器上的发生频率，也不归因于 C# Core 迁移。独立探针的前期资源解析及 AppDomain 清理故障为验证基础设施问题，原输出保留，不能当作产品失败或正式通过证据；正式验收使用应用自身入口。

## 修改范围

- 列表重绘、详情重绘和修复状态恢复后逐次检查原有请求身份；已返回、已切换目标或已被新操作替代时，直接退役。
- 系统打开前再次检查取消。系统回调返回后，仅当前请求清空自己的提示，新的读取及其错误继续由新请求发布。
- 保留原生隔离重读、共享目录与路径检查、错误提示、取消与 finally 清理；不改安装和下载任务，不修改外部配置，不创建额外目录。

未修改动画控制器、曲线、时长、焦点或标题导航；新增回归核对旧操作不会替换已经接受的返回时钟，动画完成后页面与输入恢复。测试暂停时钟仅用于稳定检查身份，随后用原控制器 Finish 收尾，不将其解释为真实帧率验收。

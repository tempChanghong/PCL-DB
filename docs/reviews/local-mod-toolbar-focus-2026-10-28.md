# 本地 Mod 底栏退场的键盘焦点

基线：`3fd8d05`。继续检查选择快捷键和动画的焦点联动，确认底部“取消选择”按钮会在自身持有键盘焦点时触发所在操作栏退场。

## 依据与问题

重读固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 `PageInstanceMod.xaml.vb`、`MyScrollViewer.vb`。上游底栏沿原时长退场再收起，滚动控件也有避免焦点导致自动滚动的处理（其中 #3854 针对滑块焦点）。固定 Git 原始字节及摘要见 `artifacts/local-mod-toolbar-focus/source/manifest.json`。

PCL-DB 的操作栏使用可聚焦按钮。通过键盘激活“取消选择”后，原实现只改变选择数、命中测试和可见性；焦点仍停留在退场按钮上，控件收起后失去可用目标。关闭动画、直接收起时也存在同样问题。

## 修复

在选择数从非零变为零时，先判断焦点是否确属操作栏，以及当前实例、页面输入和读取状态是否仍有效。满足条件时，在退场或收起前把焦点交回 Mod 列表，并恢复原滚动偏移。原动画、计数和完成清理规则保持。

焦点交接同步完成，退场完成回调不补发聚焦操作。搜索造成的选择清理、顶部全选按钮、文件读取／写入和页面切换沿各自原流程处理，避免抢走新的编辑器或设置页焦点。未修改文件操作、安装、下载和外部配置逻辑。

基线 `b549cae5e878fec2e78e6157be8dec5d11959588`。恢复 Mod、数据包、资源包、光影包的搜索、详情、版本选择、必需前置链接和另存为下载。PCL2 为核心，PCL-CE 不引入新的页面风格。版本保持 Beta 4.1，不打包发版。

## 固定依据

PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8`：`PageDownloadLeft`、`PageResource.xaml/.vb`、`PageDownloadCompDetail.xaml/.vb`、四种资源页 XAML、`ResourceSearcher`、`ResourceVersion` 和 `ResourceProject`，共十二份原字节快照。Git blob 和 SHA-256 保存于 `artifacts/community-rescue/source/manifest.json`。分类条目和四个侧栏图标直接来自这些固定文件，原 44 份源码及 20 项素材清单不变。

参考接口：[Modrinth 搜索](https://docs.modrinth.com/api/operations/searchprojects/)、[版本文件和依赖](https://docs.modrinth.com/api/operations/getprojectversions/)、[CurseForge Core API](https://docs.curseforge.com/rest-api/)。Modrinth 的 `project_type` 与 `all_project_types` 不能混同；CurseForge 的项目分类也不应全部当作整合包。

## 实现

- 保留现有 `Modpack*` 公共类型和默认整合包行为，增加请求/项目/文件的资源类别。复用双平台分页、部分来源失败、加载提示、结果行、分组卡片和动画；没有复制四套搜索器，也不做全仓改名。
- 下载侧栏为原版游戏与社区资源五项，顺序和图标取自固定 PCL。各资源保留草稿、来源、分类、加载器、接受的搜索会话、分页及滚动；切换取消旧页面请求，不接受迟到结果。Mod 显示加载器筛选，原版和整合包的既有控件与输入保留。
- 按具体版本的加载器和文件类型过滤混合 Mod/数据包/插件；同一发布同时带 JAR/ZIP 时分别选择正确文件，排除源码/开发文档等附件。资源版本不经过整合包兼容性/安装器。
- 必需前置按 PCL 的分组形式展示；名称查询独立、有并发上限，失败仍可点链接重试。保留平台/项目/固定版本 ID，版本独有依赖先验证所属项目；从前置返回原详情，再返回原搜索。固定数据包前置不会误用混合项目的 Mod 文件。
- 自身依赖和重复声明不显示；本工具不自动安装加载器 API，因此保留 Fabric API、Quilt API 等实际必需链接，不照搬上游相应的排除项。详情返回搜索时保留同一项目正在进行的版本请求，避免重新进入时重复下载；切换资源类别仍取消旧类别请求。
- 另存为保留原始文件名，优先使用当前已识别实例的实际运行目录及存在的资源子目录；没有明确实例时使用所选游戏目录。数据包首批只另存为，未猜测存档位置。保存选择器取消不创建任务，目录与文件选择均冻结后交给下载任务。
- 沿用既有高速下载、缓存租约、来源主机、重定向、长度及全部声明摘要校验。缓存和目标分离；保存前对同一只读句柄再次校验，再用同目录自有临时文件句柄原子重命名，拒绝覆盖。取消/失败只回收自己的临时文件，保留竞争者创建的文件。
- 保存到 `mods` 时共用本地 Mod 的物理目录互斥、启停别名检查；能识别当前实例时同时冻结并复查其配置。通用保存也锁定目标目录链，拒绝链接与 Windows 设备名。新增资源不能进入整合包安装器创建实例。
- 任务页只展示资源下载/校验与文件保存，使用独立进度权重；完成后可打开保存文件夹，返回保留原发布选择，未伪造游戏实例路径。

## 本批边界

自动安装前置、安装到指定实例、资源包/光影启用、数据包存档选择及在线更新留待后续。已有原版/组件/整合包安装、本地 Mod 启停导入、外部启动器和个性化配置继续保留。

原生 Windows 保存对话框沿用系统组件；自动化以注入路径/取消选择验证完整的版本行衔接，未模拟点击真实系统对话框。WPF 检查使用隐藏表面和受控时钟，明暗截图用于布局核对，不等于桌面帧率、真实触屏或游戏内兼容性验收。

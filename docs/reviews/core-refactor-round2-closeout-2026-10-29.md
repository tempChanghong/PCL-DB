## 达到门槛后的候选路线

1. **本地 Mod 文本解析边界。** 首候选是从 LocalModCatalog 提炼私有无状态 MetadataParser，涵盖 Fabric／Quilt／LiteLoader／旧 Forge／TOML 的文本解析。Read／Scan、ZIP／流、取消、大小限制、图标字节读取和 LocalModEntry 留在原边界；保留旧入口、严格解析规则、文化与 JSON 行为，以逐成员映射和真实旧／新结果差分验证。不是只增加 partial 文件，也不替换 JSON 库。
2. **外部配置和实例解释。** 区分原始配置快照／目录读取与元数据解释，保留三启动器配置只读、目标绑定、隔离和 fingerprint／guard 语义；不照搬参考启动器的写配置行为。
3. **操作生命周期编排。** 在前两项稳定后再考虑内部操作上下文，保持原 token、首故障、worker 全部汇合、预算释放和原子发布；不同时重做界面架构。

第三轮不自动等于整套 WPF 迁到 C#；现有保留 VB 界面、VB 测试与 net48 的约定仍有效。

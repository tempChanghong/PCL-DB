## 复现与处理

- **无效下载设置的入口顺序。** 指定实例安装缺少另存为/整合包入口已有的限速校验，能够先进入目标弹窗，再因限速无效而无法启动任务。现在先验证并定位到设置项，不创建弹窗或任务；改正后返回原详情继续安装。
- **焦点与迟到目录读取。** 返回设置后，隐藏检查表面能保留旧设置焦点；直接调用 `Focus()` 无法可靠设置弹窗的逻辑焦点。另外，目录返回后无条件聚焦版本框，会抢走用户已移至“取消”的焦点，影响长正文阅读。复用既有 `FocusPromptTarget` 明确设置初始逻辑焦点并保留滚动位置；当前弹窗已有有效焦点时保留它。新增延迟返回复现及原始失败记录，没有放宽断言。
- **存档变化后的原位重试。** 旧存档快照被拒绝后，原弹窗没有重新读取入口。增加使用现有 PCL 控件的紧凑“刷新”：取消旧存档读取，重扫冻结启动器的实例，保留原实例名称，清空旧存档选择。必须显式重选后才能确认，不修改 `level.dat`，也不自动创建存档或覆盖隔离设置。
- **同目录绑定不混用。** 目标列表过滤不属于本次冻结启动器绑定的实例；即使 HMCL 与 PCL 指向同一个 `.minecraft`，也不混用配置来源。晚回包仍受原请求所有权与取消保护，确认后仍核对当前目标。

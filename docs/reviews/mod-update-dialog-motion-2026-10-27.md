# Mod 更新确认窗口动画检查

基线：Beta 6.0 的 `c9a27bc38965b053ad5f2c4a123a17452f4b220d`。本轮修复更新／删除确认窗口及其共用弹窗的动画交接，保留下载安装、备份、隔离与外部配置机制；验证后本地 Commit，不打包、推送或发版。

## 源码依据

读取固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 `MyMsgText.xaml/.vb`、`PageInstanceMod.xaml.vb` 和 `ModAnimation.vb`，逐个验证原始 Git blob。文件、blob ID 和 SHA-256 在 `artifacts/mod-prompt-motion/source/manifest.json`，上游工作目录未修改。

PCL 的 Mod 更新先显示确认框。`MyMsgText` 进入时从 Y=40、-4° 开始，60 ms 后执行 120 ms 淡入及 300 ms Weak Back 位移、Weak Fluent 旋转；关闭时重复按钮由 `IsExited` 拦截，20 ms 后执行 80 ms 淡出，150 ms 位移／旋转，遮罩在 30 ms 后开始 200 ms Weak Fluent 淡出。新弹窗沿用当前遮罩，旧弹窗不能清掉新弹窗。

## 复现及修复

- **停在上一帧。** 原实现在时钟 `Completed` 中读取当前属性作为基值；WPF 此时可能尚未更新最后一帧。将入场定位到 90 ms 后立即结束，原实现保留了 opacity=0.25、Y≈28.8686、-3.24°、遮罩 alpha=41。现在中断时仍采样当前画面，自然结束时则在移除时钟后明确写入最终值。
- **重复取消截断退场。** 结果已完成、退场仍在运行时，再次调用取消会立即隐藏窗口、解锁背景。现在参照 PCL `IsExited` 忽略重复完成通知；关闭应用或明确禁用动画仍可清理。
- **固定等待期限误取消。** 原 Mod 确认最多轮询 1.5 秒，调度延迟或暂停退场后，已经接受的更新会被当作取消。改为等待所属弹窗的关闭回执。应用关闭会完成等待；替换弹窗返回失败，旧确认不会批准新页面的文件写入。
- **遮罩闪变。** 重开时沿用上一窗口当前显示的遮罩色，不再重新从透明开始；退场遮罩的 30/200 ms 时序和 Weak Fluent 曲线与 PCL 对齐。旧时钟失去所有权后不能改写新窗口。
- **返回按钮和操作栏。** 确认返回实际的更新／删除按钮；浮动操作栏是滚动区的兄弟元素，按所属页面核对可见边界，滚动行仍按滚动区裁剪。背景重新启用后先重算 Mod 操作门控，再交还焦点，修复父控件启用通知过早取值导致底栏仍禁用的问题。实例失效或文件正在操作时继续禁用。

## 验证

新增 31 项 WPF 专项，接入 all、navigation 和 motion。涵盖明暗主题、入场 90 ms／退场 20 与 80 ms 采样、重复取消、遮罩交接、旧时钟、延迟超过 1.5 秒、实例退役、实际按钮焦点、操作栏门控、减少动画及实例／Mod／配置字节保留。

原行为先执行 29 项断言，其中 16 项通过、13 项失败；之后增加两项底栏门控检查，修复后专项 31 项全部通过。中间失败回执、属性采样和图片均保留。完整回归策略为 `PCL-DB-checks/2026-10-27.1`：all 2,062；motion 1,532；pack-search 1,169；navigation 908 包含在 all 中，计数不能相加。固定 PCL 源码／资源与 97 项验证契约检查另行执行。

第一轮完整界面和动画通过；搜索回归中的六条管理页取消检查原先假定任务结束时弹窗已经消失，依赖了重复关闭通知截断动画的旧行为。按 PCL 结果先完成、退场后移除的顺序，让检查等待真实退场结束，保留原有取消状态、焦点和配置断言。失败回执保留在 `regression/pack-search`，修改夹具后重新执行三组回归，最终回执在 `regression-final`。

最终以 `artifacts/mod-prompt-motion/validation.json` 和分组回执为准。仅使用临时实例、受控更新候选、实际 WPF 时钟和离屏布局，没有联网下载或修改用户 Mod／启动器配置。没有改动 Core 下载及文件发布实现，本轮未重新执行核心 7,187 项套件；未进行人工桌面帧率或所有 DPI 验收。

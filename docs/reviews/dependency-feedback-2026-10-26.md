# 前置链接失败提示的页面归属

日期：2026-10-26。基线 `03cbaca8c9931ef2fd5f2d14a4b393195ab1d634`。Beta 5.0 后续本地源码，尚未发行。

## PCL2 依据

固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 `PageDownloadCompDetail` 从 `PageCurrent.Additional` 获取当前项目、版本和加载器条件；`UpdateFilterResult` 重建当前版本分组，前置资源位于各分组内容中。`MyPageRight` 按当前页面呈现加载状态，`ModLoader` 区分失败与取消。三份原始 Git 对象和 SHA-256 在 `artifacts/dependency-feedback/source/manifest.json`。

PCL-DB 的前置解析是异步扩展，因此额外核对失败提示是否仍属于当前可见链接；没有照搬网络请求或改变原有返回栈。

## 问题与修复

前置查询成功时已经检查点击来源，但失败分支只检查请求和项目。切换版本筛选或折叠原版本卡片不会更换项目，旧链接稍后失败时，仍会把“无法获取前置”写入当前详情页。

失败分支现在同时要求来源链接仍在可见页面中。已经过滤、折叠或离页的来源不能污染当前提示，也不会改变筛选、行、展开状态或返回栈。

没有用临时输入门控判断错误归属：仍可见的当前链接在入场动画期间失败，仍会显示可重试错误。保留现有页面动画时钟、网络回退、前置固定版本、详情缓存、下载/安装管线及外部配置。

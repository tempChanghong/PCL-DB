# Forge／NeoForge 处理器散列取消

基线 f9bbb2071ae9ab1b52f22d8141355d6c3d63f144。本轮继续第三轮重构后的阶段校验收尾，保留 VB WPF、VB 测试、net48 及程序集／接口／配置／资源身份，不打包发版。

## 问题与最小修复

InstallForgelikeAsync 中四处 Matches 未传调用方 token：私有依赖筛选、输出首次复用、整组输出确认，以及处理器执行／复用后的最终输出校验。虽然阶段之间已有取消检查，但一旦开始散列，原调用仍会读完文件；较大的处理器输入或输出会延迟取消。

只为这四处原调用增加原 token，复用既有的分块散列，没有新增源、任务或生产测试钩子。取消和错误同时发生时遵守 Matches(token) 既有取消语义，不声称所有异常先后顺序都不变。

## 逻辑与冲突边界

- DownloadPlan.Merge 仍先完整合并并检查声明冲突，再执行 Where 的文件复用筛选；不能因第一个弱匹配而隐藏后面的冲突或更改首 URL。
- 输出复用仍须非空且所有摘要均为完整 SHA1。All 保留短路，缺失／损坏输出仍沿原缓存恢复或处理器执行流程；无输出及不完整输出的 NeoForge 处理器仍执行。
- “跳过处理器执行”不等于不启动任何 Java 进程：原 JavaRuntime.Find 在复用判断前仍可能进行版本探测。
- 最终输出先全部校验，再逐个写入内容寻址缓存。取消不能把本处理器尚未验证的输出作为完成结果，但已有完整缓存和先前已验证阶段的缓存保留供重试，不进行全局缓存回滚。
- 四处均在私有工作树及运行库／实例发布之前。原文件流释放、任务工作树清理、并行同级故障归属、共享库冲突和成功实例的非取消清理均不改。

## 源码依据

以 PCL2 固定 5ef81e490ae46b1100d61e33d0183094c7a80ca8 的 ModDownloadLib、ModLoader 为核心核对依赖补全、处理器及取消边界；C# 重点参考 CE 915ac29795efbdf6373417389e181e1504117048 的 LoaderDownload、FileDownloader 与资源释放。具体固定 Git 原字节、行号、摘要、四实参逆向及独立阶段审查见 artifacts/forgelike-hash-cancellation/audit。

CE 的 Task.Run(checker.Check, token) 不证明运行中的 checker 会按块取消；PCL-DB 沿用自己的 Matches(token)，不宣称上游具有相同缓存、冻结租约或私有树协议。

## 验证与限制

新增回归沿真实 InstallAsync 链进入现代 NeoForge 安装器夹具，覆盖两种组件共用的实现，使用已有 FixtureProcessor 资源。通过实际生产调用栈和受控输入区分依赖 Where、输出复用、All 确认及执行后校验，排除下载器／VerifiedComponentCache 的散列；在既有 CryptoConfig／FileMatchHashProbe 首块回调取消，保留原算法映射与回调。校验取消归属、处理器执行次数、共享库／隔离设置、私有树清理、缓存和同名新令牌重试。

新增 47 项：四阶段各 11，加两个 SHA1 别名与回调恢复 3。使用 25000 个中文字符生成 75000 个 UTF8 字节，既在 Windows 命令行长度内，又超过一个散列块。同一新宿主配旧 DLL 为 43/47、四项预期早停失败，各读取 75000 字节／19 块；修复后为 47/47，各读 65536 字节／1 块停止。四案的处理器执行次数（取消前／取消后／重试后）分别为依赖筛选 0/0/1、已有输出 0/0/0、缓存恢复后 All 1/1/1、执行后校验 0/1/2；取消没有误触发处理器或提前保存未校验输出。现有 8076 项保留，全量增至 8123。这里只测真实声明使用的 SHA1，不称全算法交叉。

All 谓词因捕获 token 改变了编译器生成的闭包身份；测试按参数类型及所属生产状态机调用栈定位，成功跨旧、新闭包差异，不写死生成名称或靠第 N 次散列猜测阶段。

最终验收还包括当前 VB 全量、原 Beta 8 编译宿主、当前 C# 原始／规范 API 与资源／配置比较、Release／VS2026 Debug，以及同一冷目录单 EXE 启动／兼容和两依赖／七份根文档摘要。实际计数、进程、输入与源码摘要、提交树绑定在 artifacts/forgelike-hash-cancellation/validation.json。原 Beta 8 严格元数据比较保留两条历史 Friend 新增差异，不把旧宿主通过冒充精确元数据相同。

本轮不改 UI 和动画，不另跑完整 UI／motion／搜索专项。安装器为合成夹具，Java 处理器为现有测试资源；不证明任意真实上游安装器、游戏运行或真实网络／取消延迟／吞吐量。没有用户实例或外部启动器配置写入，未打包、推送、发版。

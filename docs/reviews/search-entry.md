# 搜索界面入口与页面归属

基线 `f130d7190ef5682640e3b57f0e16a601e7466431`，工作分支 `main`。核心依据固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 PageResource 与 MyPageRight；没有引入新的 CE 布局。

## 复现与修正

清空文本入口已经检查实际搜索页可交互，但搜索按钮/回车与重置没有同样的界面归属校验。受控 WPF 中先接受 `entry-baseline`，切到设置页，再向隐藏编辑器发送迟到回车，旧实现记录 `settingsVisible=true`、`sessionChanged=true`、`acceptedText=retired-search-input`。原始状态为 `reproduction.state.json`，失败回执为 `reproduction.json`。

- 搜索按钮、名称/版本输入框回车和重置图标经共享界面校验，确认当前为整合包搜索页、表单已加载且可见可交互、页面门控放行，事件来源也可见且启用。忙碌、关闭、命名期间拒绝旧输入。
- 校验通过后仍调用原有内部搜索或重置方法，保留自动加载、查询身份、缓存、去重、分页和已接受的结果。重置只清草稿，不直接替换已接受搜索。
- XAML 只调整两个事件绑定；没有几何、字体、图标、颜色或动画曲线改动。快速返回门控期间不能替换当前页面时钟，放行后仍可在卡片入场期间搜索。

PCL PageResource 将按钮和回车接到同一搜索流程，ResetFilter 清草稿并使缓存失效，MyPageRight 门控退出控件。额外归属校验是本工具复用隐藏搜索控件后的补充，不宣称固定 PCL 提供相同校验函数。下载安装内核保持。

# 筛选按钮的按压所有权

基线 `a02760cc3942d9ca825503c573f0365cb62df48e`。主要读取固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 `Controls/MyRadioButton.xaml(.vb)`，沿用该控件的布局、两类配色、单选动作与动画时长。没有借用新的 CE 页面布局。

## 复现与修正

旧实现的 LostKeyboardFocus 只刷新颜色，没有清除 `_down`。真实 WPF 呈现源中按住高亮筛选按钮、发送失焦事件后释放，记录为 clicks=1、selected=true、peerSelected=false，复现旧手势改变选择；原始数据保留于 `focus-reproduction.state.json` 和失败回执 `focus-reproduction.json`。

- 增加统一的 CancelPress，仅清除按压并立即回到当前选中/悬停配色。失焦、主题变化和鼠标捕获丢失均使用此路径，已有禁用/门控生命周期也复用该方法。
- 取消不改变 Checked、不发送 Click，也不引入鼠标捕获。PCL 的普通悬停 90 ms、选中 120 ms、移出 150 ms，以及高亮/白色角色的按压颜色与时长保持。移出与正常新手势继续执行原有动画。
- 旧时钟失效后不能覆盖新状态，旧指针释放不能触发筛选；新的点击仍选择一次。实际详情页保留卡片、已构建版本行、发布文件身份与安装上下文；清单刷新后旧按钮不再有权改变新选择。

失焦与捕获取消是本工具保留键盘可达性后的补充防护，不宣称固定 PCL 已提供相同处理。XAML 布局、字体、图标、折叠逻辑、查询、版本隔离与下载安装内核未修改。

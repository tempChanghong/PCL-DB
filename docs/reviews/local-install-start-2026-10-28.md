## 复现与修复

在线整合包入口上一轮已修复；原版和本地 ZIP／MRPACK 共用的 `StartInstall` 仍在 Try 之外冻结输入、设置任务信息和切进度页。任务页可见性回调报错会进入 Dispatcher，留下忙碌状态；回调先选择管理页时，旧 `ShowProgress` 会再次切回下载页；回调请求取消后，旧入口仍调用安装器。旧本地读取也未随该入口退役。

- 接受任务后捕获本次取消源，任务准备、偏好保存和页面交接进入原有 Try／Catch／Finally。
- 先建立任务代次、名称、目录、阶段和结果身份，再冻结控件，避免控件通知看到半初始化的任务。
- 使用上一轮已有的资源退役机制，先解绑旧读取，保留当前子动画直到父页面捕获合成画面后清理；进度页切换不会覆盖通知接受的较新主页面。
- 页面交接的 Finally 仍通知所有捕获读取，即使可见性回调报错也完成退役。安装器调用前显式检查本次取消源及关闭状态。
- 运行器、真实安装器、错误判断和清理均使用本次源，避免以后续可变字段推断当前任务。原有目标预检、组件选择、版本隔离和已有实例设置保持。

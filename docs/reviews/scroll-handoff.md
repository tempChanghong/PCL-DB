# 下载与详情页的滚动交接

基线 `e934fb0cf4b84c618fea417e8b3766812a1bbaf4`。以固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 `Controls/MyScrollViewer.vb`、`MyPageRight.vb`、`MyMsg/MyMsgInput.xaml.vb`、`Modules/Base/ModAnimation.vb` 和 `Pages/PageDownload/Resource/PageDownloadCompDetail.xaml` 为依据。源码、Git blob 与 SHA-256 保存在忽略目录 `artifacts/scroll-handoff/source/`；本轮没有引入新的 CE 布局。

## 问题与修正

修改前在真实 WPF 滚动时钟的 60 ms 处禁用父级，仍可观察到控件持有滚动时钟，失败回执为 `scroll-reproduction.json`。原实现仅在隐藏、卸载和显式导航时停止滚动，未统一覆盖禁用、输入门控和动画偏好变化。

- 滚动接入现有控件生命周期策略。禁用、门控、隐藏、卸载、关闭平滑滚动或减少动画时清理当前时钟；恢复交互后只接收新手势。Windows 偏好事件继续按加载/卸载配对订阅，检查使用控件级开关，不修改系统设置。
- WPF 原生滚动请求会排队。交互中断时用当前显示位置替换尚未执行的动画请求；正常动画完成仍交由原先的完成流程处理，避免丢失最后一帧位移。实际待处理请求的同轮中断检查记录了 `pendingCount=1`，中断前后位置一致。
- 另在 29 项新检查通过后复现布局重入：确认旧请求的 UpdateLayout 期间撤销输入，后续替换手势仍走即时位移。输入权限检查移至布局确认之后，阻止这笔迟到位移；失败数据保留在 `reentrant-probe.json` 与 `reentrant-probe.state.json`。
- 页面不可交互时，完整预览/冒泡滚轮路由不能重启动画或落入外层原生滚动。横向筛选栏自身被禁用/门控时也消费旧事件；正常长度筛选栏仍交由外层滚动，溢出时保留横向归属。
- 详情介绍卡的下方间隔由默认 15 DIP 调为固定 PCL 的 25 DIP。继续保留用户已确认的紧凑动作、搜索分层与现代导入图标。

PCL 的 300 ms、六次方 Fluent、边界处理、卡片折叠期间的位移保持与页面/卡片动画不变。新增的生命周期防护属于本工具适配，不宣称固定 PCL 已包含同样实现。未修改查询、缓存、文件身份、外部启动器配置、版本隔离或下载安装事务。

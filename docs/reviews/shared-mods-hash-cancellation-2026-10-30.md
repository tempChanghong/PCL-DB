# 共享组件 Mods 校验与冻结取消

基线 3ae37284d1b140d2ec78f9ff38258423274489c2。继续审查重构后的取消与发布边界，保留 VB WPF、VB 测试、net48 及程序集／接口／配置／资源身份，不打包发版。

## 问题与修复

共享组件 Mods 下载完成后，CheckedFiles 先按远程声明校验暂存文件，再计算本地 SHA1 冻结摘要，作为最终共享文件比较与发布依据。原代码两次都不能中途取消：Matches 未传 token，本地冻结直接 ComputeHash；远程校验中取消还可能继续计算完整的本地摘要，直到函数末尾才抛出取消。

本轮仅修改此函数的两个散列调用，新增同类私有 HashStream：远程校验沿原 Matches(token)，本地冻结保留原 SHA1 provider 与同一个已打开的输入流，按 64 KiB 读取，读前、EOF 后和完成摘要后检查原 token。None 沿原 ComputeHash，取消分支取出摘要后重置 provider，保留 ComputeHash 的重置语义；不增加公开／Friend 入口或生产测试钩子。

## 逻辑、租约与配置边界

- 原 FileStream(FileShare.Read) 从远程校验前持续到本地冻结结束。Matches 的内部流关闭后，外层租约仍防止写入、删除或重命名，不能通过关闭重开流来冻结已经变化的源文件。
- 本地流仍从原位置零开始；输入路径、声明对象、冻结文件大小、小写 SHA1 和 component 分类不变。远程校验失败仍不生成冻结记录；取消时局部结果不会返回，调用方 AddRange 不接收半组结果。
- CheckedFiles 位于运行库分支完成后、共享 Mods／旧资源 Publish 及最终实例提交前。失败仅释放读保护并沿原安装 finally 清理私有树，不修改已存在的共享 Mods、实例和隔离设置。
- Preflight、旧资源 Publish、Complete、Dispose、回滚与成功后的缓存清理均不改。回滚仍先释放租约，再按冻结摘要回收本任务自建文件，不能因用户取消而跳过必要收尾。
- 取消与错误同时出现时沿既有 Matches(token) 的语义，不宣称所有错误优先级相同。也不把本轮描述为整个共享 Mods／旧资源链的所有散列都已可取消。

## 源码依据

以 PCL2 固定 5ef81e490ae46b1100d61e33d0183094c7a80ca8 的 ModDownloadLib／ModMinecraft 为核心核对组件 Mods、PathIndie 与隔离目录；C# 重点参考 CE 915ac29795efbdf6373417389e181e1504117048 的组件安装、校验、取消和资源释放。固定 Git 原字节、行号、摘要与独立阶段审查见 artifacts/shared-mods-hash-cancellation/audit。

上游的组件路径和任务归属是参考依据；本工具的冻结摘要、跨阶段租约和原子发布是既有实现。CE 的 Task.Run(checker.Check, token) 不证明已开始的 checker 会按块响应取消，不将该行为归于上游。

## 验证与边界

新增回归通过实际 CheckedFiles 和安装链，分别定位远程声明校验、已校验文件的 SHA1 冻结和无远程摘要的 OptiFine 冻结。使用原有进程内摘要探针，恢复算法映射与回调，检查首块取消、跨阶段原租约、文件状态、释放和新令牌重试；控制 None 与可取消未取消路径的相同结果、空文件、预取消、坏远程摘要。

新增 44 项：直接校验 20、实际安装联动 9、控制 9、算法／回调恢复 6；原 8123 项保留，全量增至 8167。同一新宿主配旧 DLL 为 40/44、四项预期早停失败；四案目标摘要均读满 524307 字节／129 块，修复后 44/44，均在 65536 字节／1 块停止。MD5 远程校验中取消时，随后 SHA1 冻结从旧 524307 字节降为 0；在本地冻结中取消的场景，远程校验此前已正常完成，不能把总读取量也称为一个块。

实际安装取消后保留已有共享 OptiFine、用户 Mods、时间戳、全局与已有实例隔离配置，没有发布新实例、资源别名或新选中 Mods；同名重试正确使用共享目录，已声明摘要的缓存复用，无远程摘要的测试 OptiFine 重新下载一次。跨阶段 provider 创建时仍阻止写／删／改名，退出后文件可独占打开。直接测试为单文件；部分列表不逃逸另依据局部结果与 AddRange 求值顺序审查，不称新增了多文件失败矩阵。

最终验收还包括当前 VB 全量、原 Beta 8 编译宿主、当前 C# 原始／规范 API 和资源／配置比较、Release／VS2026 Debug，以及同一冷目录单 EXE 启动／兼容和两依赖／七份根文档摘要。实际计数、进程、输入与源码摘要、提交树绑定在 artifacts/shared-mods-hash-cancellation/validation.json。原 Beta 8 严格元数据总比较保留两条历史 Friend 新增差异，不把原宿主通过冒充精确元数据相同。

这是合成临时文件、测试安装器和局部 HTTP 夹具验证，不证明任意真实上游安装器、游戏运行或真实网络／取消延迟／吞吐量；不写用户实例或外部配置。本轮不改 UI，不另跑完整 UI／motion／搜索专项。未打包、推送、发版。

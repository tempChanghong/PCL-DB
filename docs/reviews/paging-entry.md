# 搜索分页与页面输入归属

基线 `76e17dec804f6430913bf8763992b8476e109695`，工作分支 `main`。以固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 PageResource 与 MyPageRight 为依据；没有引入新的 CE 布局或行为。

## 复现与修正

此前搜索、回车和重置已经检查界面归属，首页、上一页、下一页仍直接进入内部分页方法。受控 WPF 中先接受第 2 页，切到设置，再向缓存的下一页按钮发送迟到回车：旧实现保持设置页可见，却将后台搜索切到第 3 页并替换结果行。`reproduction.state.json` 记录 `settingsVisible=true`、零基页码 `page=2`、`sameSession=true`、`sameRows=false`，失败回执为 `reproduction.json`。

- 三个分页按钮统一经界面入口，检查整合包搜索页、表单交互状态、外层动画门控以及实际事件来源的可见、启用和命中状态。详情、本地导入、原版页、忙碌、关闭或命名期间的旧分页事件不再改变后台结果。
- 放行后仍调用原有首页、上一页和下一页方法，保留已接受的搜索会话、缓存返回，以及筛掉非整合包条目后在本页“继续加载”的行为。
- 快速返回时沿用现有页面时钟；未恢复输入前拒绝旧事件，放行后允许卡片入场期间正常翻页。没有改动几何、字体、图标、颜色、动画曲线或下载安装内核。

PCL PageResource 的三个分页按钮接入 ChangePage；切页暂时禁用 CardPages、滚到顶部，再启动 Loader。MyPageRight 在入场恢复命中、退场先关闭命中并淡出/上移。本轮借鉴其输入与页面切换关系，补全本工具缓存页面的归属校验，不宣称原版有同名校验函数，也没有将其后台线程的 100 ms 等待移入本工具。

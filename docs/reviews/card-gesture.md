# 卡片标题手势与折叠动画交接

基线 `49d4989ae8fad06bb3876eda1253d1ff64429348`，工作分支 `main`。本轮以固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 MyCard、PageDownloadInstall 与 PageDownloadCompDetail 为依据，没有采用新的 PCL-CE 布局。

## 已复现的问题

卡片标题已有离开、禁用、门控、隐藏与卸载清理，但失焦只更新悬停，捕获丢失与主题变化没有取消旧按压。旧代码在真实 WPF 呈现源中“按下标题 → 路由失焦 → 松开”记录为 `started=true`、`cancelled=false`、`retainedFoldAndClock=false`：松开改变折叠并替换了原高度时钟。失败回执 `reproduction.json` 和原始状态 `reproduction.state.json` 保留在本轮 artifacts 内。

## 修正范围

- 失焦、捕获丢失及主题变化时取消标题按压；主动改变折叠状态也取消尚未完成的按压，覆盖键盘与鼠标交接后旧释放再次反转的情形。
- 只清除旧输入，不停止有效的高度与箭头动画，不修改 Body、Builder 或选择。正常的新点击仍改变一次折叠，过期高度时钟不能覆盖新时钟。
- 保留 PCL 的 40 DIP 折叠高度、展开后 34 DIP 标题点击范围、90 ms 悬停、150 ms 短距离高度缓动与原有长距离分段曲线，以及 250 ms 箭头缓动。无 XAML、字体、图标和布局改动。

失焦/捕获取消是本工具保留键盘与异步交互后的补充防护，不宣称固定 PCL 已实现同样的处理。查询、版本隔离、下载源、安装事务与打包代码未修改。

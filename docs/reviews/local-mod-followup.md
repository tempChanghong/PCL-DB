## 已复现和修正

### 导入过程中的晚到别名

原实现只在每项发布回调之前检查启停别名。用受控回调在此后新建 `late.jar.disabled`，旧内核仍返回导入成功，目录同时出现启用和禁用文件。证据位于 `artifacts/mod-actions-audit/fixture-39b178ab7b804247978568785abb3bec/result.json`。

现在在实际重命名前后及整批成功前复核别名；最终复核包括先前已发布项和同内容跳过项。若出现冲突，仅通过已有自有句柄回收本次新增内容，保留外部别名、原有文件和源文件。启停重命名后也复核别名，失败沿用现有恢复路径，不覆盖被外部占用的原名。仍不能阻止独立外部程序在操作返回后继续改动目录。

### 合法多行 TOML 被误拒绝

Forge/NeoForge 多行字符串结束处的四/五连续引号，以及行尾反斜杠后带空格或 Tab 再换行的合法续行，原来会使识别显示问题并导致导入失败。现在正确保留一/两个字面引号并折叠合法续行；没有换行的空白转义、非法单行续行、未闭合字符串继续报错。

独立 Python `tomllib` 验证 11 类合法和 7 类非法文档，完整输出位于 `artifacts/local-mod-audit-catalog/followup-oracle.json`。新回归同时检查真实识别与 `ImportFiles`，覆盖 Forge、NeoForge、多 Mod 记录及不应成为 Mod 的注释/依赖文字；损坏文件仍保留禁用能力。此解析器仍只解释信息展示所需的格式，不扩展为完整 TOML 或依赖校验器。

### 目录快照与过期页面刷新

原 Mod 页刷新只扫描进入页面时冻结的旧实例。外部启动器更改隔离设置后，刷新会一直被旧快照校验拒绝，必须返回列表才能恢复。显式“刷新列表”现在先只读重新解析同一启动器、同名实例，再扫描新实际目录；成功后一起交接实例模型、路径、共享提示和列表。失败保持写入门控，可再次刷新。离页、换实例、换绑定和新请求会使旧结果失效。

另修复管理根扫描虽已过期，其外层刷新延续仍能重新加载新实例 Mod 页的问题。延续现在核对扫描代次、绑定、成功状态及文件写入状态，避免取消后的旧扫描干扰新的导入状态。新目录中的状态不接收旧目录文件操作结果。

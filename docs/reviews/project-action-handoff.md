# 详情复制重试与输入交接

基线 `3888333ef4efba38a464a2d121ede4047efb6039`，工作分支 `main`。以固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 PageDownloadCompDetail、ModBase.ClipboardSet 与 MyMsgInput 为依据，没有采用新的 CE 布局或交互。

## 复现

现有异步复制按 PCL 参数重试，离开详情或替换项目会撤销操作，但介绍卡失去输入权限后再恢复并未更换操作代次。受控剪贴板占用一次、等待期间打开并取消真实命名弹窗，旧实现继续第二次复制并显示“已成功复制！”。原始 `calls=2` 与反馈保存在 `reproduction.state.json`，失败回执为 `reproduction.json`。

## 修正

- 介绍卡 IsEnabled 或 IsHitTestVisible 变为 False 时退役项目操作，涵盖直接禁用及父级继承。恢复 True 不恢复旧操作；待重试的复制与打开网址失败后的复制回退都必须通过既有代次校验。
- 恢复后新点击获得新代次，可立即成功。旧操作不能在命名弹窗取消后再写剪贴板，亦不能覆盖新反馈。
- 局部版本内容入场只门控版本区，仍可交互的介绍卡保持可用；原有四次尝试、200 ms 异步间隔、项目 URL/名称与浏览器失败回退保持。

PCL 原版提供复制入口、重试和弹窗动画参考；本工具异步重试的输入归属取消是补充实现，不宣称原版有相同取消机制。XAML、字体/图标、页面与弹窗曲线、搜索/版本数据、安装事务和打包代码未修改。

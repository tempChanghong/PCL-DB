# 本地 Mod 管理：第二批

基线 `caf4a8472e8040d22ef580ca4dcfa5ceaa372e04`。在第一批实例管理上增加「Mod 管理」，先实现本地识别、启停和导入，不包含在线 Mod 搜索、更新、删除或依赖自动处理。本轮仅本地提交，不改版本号、不打包发版。

## 源码与界面

PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 `LocalResourceFile/LocalResourceLoaders` 决定扫描后缀和实际 Mods 目录；`PageInstanceMod/InstallMods` 决定启停及导入为启用名称的行为；`PageInstanceMod.xaml`、`MyLocalModItem.xaml` 提供搜索、筛选、44 DIP 行和右侧启停图标。PCL-CE `915ac29795efbdf6373417389e181e1504117048` 的 `ModLocalComp` 仅补充本地元数据读取参考。

原字节副本、Git blob 和 SHA-256 在 `artifacts/local-mods/source/manifest.json`。沿用原有 PCL 字体、卡片、图标按压、胶囊筛选、滚动和逐项页面入退场。过滤重用已有行，刷新只清理过期行；返回概览保留滚动位置。没有接入 PCL 的联网关联，也不照搬导入前删除已有同名文件的逻辑。

## 识别和范围

`LocalModCatalog` 只读枚举实例实际运行目录的 `mods` 直接子文件，不创建缺失目录。支持 `.jar/.zip/.litemod` 及它们末尾单个 `.disabled/.old`；不移除文件名中间的字符串，重复状态后缀不静默修正。启用与禁用同名文件分别保留，重复 Mod ID 和状态别名并存显示警告。

离线读取 Fabric、Quilt、Forge/NeoForge TOML、旧 `mcmod.info`、LiteLoader 及 JAR 主清单，识别多个 Mod ID、版本占位符和主清单续行。只做有界元数据读取与名称/版本/ID/加载器显示，不执行 JAR，不从文件名断言兼容性。TOML 读取器只解释本地信息所需的表和字符串，依赖、嵌套子 Mod 和加载器兼容性不由它推断。

SHA-256 对完整文件流式计算；显示值限长而真实路径、文件名和摘要保持完整。有效未知 JAR 保留警告；坏文件和读取失败单项显示问题。读取成功但归档损坏的文件仍可禁用，读取失败且没有可靠摘要的条目不可启停。

本批尚未扫描旧 Forge 的版本号子目录，也未实现 Jar-in-Jar 内嵌 Mod 展开。原版实例可查看其真实 Mods 目录，导入文件不会自动添加加载器或改写版本配置。

## 写入、共享目录与冲突

`LocalModActions` 使用第一批冻结的启动器、实例和实际运行目录。PCL、CE、HMCL 的新旧隔离规则保持；配置或目录推断发生变化时停止，不初始化隔离设置。共享 Mods 显示影响范围，同一物理运行目录通过文件身份键与命名互斥串行，游戏根目录同时使用原有安装锁。

启停基于扫描时的长度和 SHA-256，在同一文件句柄上校验并执行不覆盖的重命名。目标名称、启停别名、文件/目录或链接冲突均拒绝；`.old` 启用后还原为原始有效扩展名，禁用统一追加 `.disabled`。

导入仅收 JAR、LiteMod 及其单个状态后缀，按 PCL 使用启用名称。现有 ZIP Mod 可识别/启停，任何 ZIP 状态变体都不绕过整合包入口进入新导入。未知但有效 JAR 可导入并显示警告，无效归档或无法解析的声明拒绝导入。

所有源文件先读取、持有并校验，再以私有暂存流式复制；同内容已有文件跳过并保留现状，同名不同内容或禁用别名冲突拒绝整批操作。源文件不移动、不覆盖。发布文件持有自有句柄，异常/取消只回收本操作新增内容，不能按路径删除后来替换的文件。实际 Run/Mods、私有暂存及祖先目录租约保护操作期间的目录身份；显式导入可创建缺失的 Mods，但不创建尚不存在的自定义运行根目录。

Windows 句柄行为依据 [CreateFileW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew)、[FILE_RENAME_INFO](https://learn.microsoft.com/en-us/windows/win32/api/winbase/ns-winbase-file_rename_info)、[SetFileInformationByHandle](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-setfileinformationbyhandle)。批量异常/取消有回滚；没有实现进程崩溃恢复日志，不保证强制终止进程后的整批回退。

## 页面与任务联动

后台读取按实例与代次交接，离页、快速反向或切换实例后忽略旧结果。文件操作保持冻结来源，允许浏览其他页，但禁止重复写入、修改目录绑定或启动新的安装。取消及关闭窗口等待文件操作退出；下载、外部配置恢复期间禁用本地 Mod 写入。

操作完成刷新当前所属目录。期间浏览别的实例时显示真实操作来源，完成后刷新当前视图而不把旧结果串入新实例。设置返回和管理刷新会重新读取保留的 Mod 页；重扫失败保留错误并禁用旧列表写入，直到刷新成功。操作代次和读取代次分别保护状态、输入门控和旧动画清理。

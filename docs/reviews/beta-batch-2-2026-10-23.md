# 远古版本补充：三个 Beta 1.8 预览版

本轮按[首批 Beta 报告](beta-batch-1-2026-10-23.md)的分组结果，接入 `b1.8-pre2`、`b1.8-pre1-2`、`b1.8-pre1-1`。累计支持 83 项补充版本：67 项历史快照、13 项远古补充和 3 项 2.0 三色版。归档历史候选支持 80/171 项，剩余 91 项（24 项字段完整、67 项缺少库／索引声明）。不将补充清单覆盖率视为游戏启动或存档验收。

`b1.8-pre1-2` 的 URL 省略末尾 `-2`，另一个 pre1 修订的 URL 保留点号。因此只增加两项明确路径映射，不对 b1.8 批量替换前缀。两个 pre1 日期相同但客户端不同，显示、安装 ID 与摘要各自保留；不合并为含糊的 `b1.8-pre1`。路径 ID 不自动成为别名，未知 pre3 不开放。

pre1-1 的上游客户端 `size` 是字符串。现有计划解析器可读取该十进制大小，原始 JSON 与归档夹具保持不变，不为本批增加通用类型转换或重写元数据。归档 SHA-256 只核对本地原始夹具，不冒充 UVMC 公布的元数据摘要。

Beta 只读注册表增至 10 项。分类与启动配方继续分离，RC1 仍优先使用原有 LaunchWrapper 1.6／AlphaVanillaTweaker；既有 Classic、Infdev 与 2.0 特例保持原有边界。

## 固定 PCL 源码对照

参考提交 `5ef81e490ae46b1100d61e33d0183094c7a80ca8`，五份本地参考与对应 Git 对象在标准化行尾后核对：

- `ModDownload.vb / DlClientListBmclapiMain`：附加清单并入现有安装流程。保留补充源独立限时、失败不阻塞正常列表、官方同名优先及冲突声明拒绝。
- `ModDownloadLib.vb / McDownloadClientLoader`：支持库与资源阶段并行，保留原始 `clientVersion`；继续复用现有选源、共享预算、缓存校验及原子发布。
- `ModDownloadLib.vb / McDownloadListItem`、`PageDownloadInstall.xaml.vb / ShowMinecraftVersionList`：old_beta 使用远古分类、圆石图标、42 DIP 行和日期排序。本批进入现有“远古版本补充”卡片，两个同日修订均可单独选择，旧普通行、最新推荐和页面动画沿用原机制。
- `ModMinecraft.vb / McLibListGetWithJson`、`McAssetsListGet`：库规则与资源映射继续沿用。`map_to_resources` 落在有效隔离目录的 `resources`，共享目录同名异内容时拒绝覆盖与发布。
- `ModLaunch.vb / McLaunchArgumentsReplace`：`${game_directory}` 跟随有效隔离目录，`${game_assets}` 保留根目录 `assets/virtual/legacy` 语义。已有实例 JSON、INI、隔离设置与用户参数保留。

源码：[ModDownload](https://github.com/Meloong-Git/PCL/blob/5ef81e490ae46b1100d61e33d0183094c7a80ca8/Plain%20Craft%20Launcher%202/Modules/Minecraft/ModDownload.vb)、[ModDownloadLib](https://github.com/Meloong-Git/PCL/blob/5ef81e490ae46b1100d61e33d0183094c7a80ca8/Plain%20Craft%20Launcher%202/Pages/PageDownload/ModDownloadLib.vb)、[PageDownloadInstall](https://github.com/Meloong-Git/PCL/blob/5ef81e490ae46b1100d61e33d0183094c7a80ca8/Plain%20Craft%20Launcher%202/Pages/PageDownload/PageDownloadInstall.xaml.vb)、[ModMinecraft](https://github.com/Meloong-Git/PCL/blob/5ef81e490ae46b1100d61e33d0183094c7a80ca8/Plain%20Craft%20Launcher%202/Modules/Minecraft/ModMinecraft.vb)、[ModLaunch](https://github.com/Meloong-Git/PCL/blob/5ef81e490ae46b1100d61e33d0183094c7a80ca8/Plain%20Craft%20Launcher%202/Modules/Minecraft/ModLaunch.vb)。

新增回归逐项核对归档 URL，拒绝猜测路径、跨版本 URL、修订元数据互换、路径 ID 冒充别名及未知版本，要求错误条目不能掩盖有效邻项。两个同日 pre1 必须同时保留独立 ID 与客户端摘要，并校验原始字符串大小的解析结果。既有回归自动扩展至本批三项，覆盖错误分类／pending 拒绝、取消、隔离、已有设置保留和补全。

全部 67 项快照与 10 项 Beta 参与受控共享资源冲突回归：隔离安装保留不同的共享资源；关闭隔离拒绝覆盖和发布；由测试明确纠正冲突后同名重试。真实固定摘要的 wrapper 搭配合成客户端／资源的受控测试，不代替真实联网安装。

联网验收在新目录逐项安装本批三个真实版本，不读取外部游戏目录作复用源；后续版本仅复用本轮已校验文件。逐项核对客户端、库、索引与资源摘要，检查发布前取消、同名重试、UTF-16 JSON／INI 原字节及隔离设置保留、损坏客户端补全。另以全量入口检查 83 项补充版本与普通 `rd-132211` 的在线元数据／索引；不将此称为 83 项全部重新安装。

源码清单、固定 PCL 核对、归档摘要、定向进程、联网安装、全量元数据、构建及最终成功回执保存在忽略目录 `artifacts/beta-batch-2/`。源码清单和二进制摘要绑定本轮验证，最终数量及成功状态以 `validation.json`、`live-binding.json` 为准。在线元数据的重新序列化副本仅作诊断，不替代原始夹具或上游摘要。

本轮不启动游戏，不提供 PCL GUI、Java 兼容性、游戏内资源或创建／保存／重进世界的人工验收结论；不打包、不发版。

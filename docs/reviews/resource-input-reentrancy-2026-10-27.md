# 资源安装弹窗：刷新与实例切换的取消重入

基线：`9170a29`。沿资源安装弹窗继续检查刷新、实例切换、存档选择和动画关系。本轮仅修复 UI 输入归属；下载、文件发布、版本隔离及外部配置读取实现保持，不打包、推送或发版。

## 依据与复现

重读固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 `MyMsgSelect` 和 `PageInstanceMod.ReloadModList`：保留选择确认、显式刷新及回到顶部的操作习惯。原始 Git blob 与 SHA-256 在 `artifacts/resource-input-reentrancy/source/manifest.json`。本工具的异步存档请求与输入代次是补充实现，不宣称上游存在相同接口。

在受控取消回调中复现三种情况：

- 旧刷新取消存档读取时，回调关闭原窗口并打开光影选择器、选择另一个实例。旧刷新随后继续清空新窗口列表，按旧实例名重读，覆盖新选择。
- 回调在同一窗口内完成更新的刷新，再明确选择实例和存档。父请求没有变化，因此只比较请求身份不能辨别先后；旧外层刷新又发起一次读取，恢复原实例并清空新存档选择。
- 旧实例事件取消存档读取时，回调已选择另一个实例并读完、选好存档。旧事件继续清空列表并再次启动存档读取，导致最新明确选择丢失。

## 修复

每个选择窗口保存独立输入代次。刷新与实例事件在取消前取得窗口、父请求及输入代次；取消返回后同时检查三者及请求状态。新窗口、同窗的新刷新或实例选择均会使旧流程退出。刷新使用取消前捕获的启动器和父请求，不再重新读取可能已换代的全局对象。

正文滚动清理在归属检查之后执行，仍保留正常刷新的滚动回顶，同时避免旧流程清理新窗口或新输入的阅读状态。原有弹窗入退场、焦点门控、存档校验和安装计划绑定保持。

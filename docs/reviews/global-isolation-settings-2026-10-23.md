## 固定 PCL 源码依据

重新读取未限制 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 PageSetupLaunch.xaml / .vb、ModMinecraft.vb、ModModpack.vb 和 PageDownloadInstall.xaml。规范化副本、源路径及 SHA-256 位于 `artifacts/isolation-settings/source/`，收尾再次对照 Git 对象。

PageSetupLaunch 的“默认版本隔离”是设置页中的 28 DIP 标签/选择框行，标签右边距 25，按顺序提供关闭、可安装 Mod、非正式版、两者、全部五种策略；提示只对之后新安装的版本生效。ModMinecraft 优先使用已有实例的 V2 / 旧设置和目录信号。ModModpack 对整合包覆盖层保留隔离实例。本工具继续提供默认“跟随 PCL”，其余五项使用相同策略值与分类规则。

## 界面与偏好

- 删除安装页 IsolationCard，不保留隐藏的逐版本选择框。Minecraft 卡片后直接衔接组件卡片，恢复原先被隔离卡片占用的布局。
- 设置页“游戏”卡片统一包含游戏目录和“默认版本隔离”。复用现有 PclComboBox、标签列与主题资源，提供跟随 PCL及其五种策略，安装页和整合包页没有单独开关。
- 新偏好 `defaultIsolation` 存储在 PCL-DB 自己的设置中：`-1` 跟随；`0..4` 与 PCL 的默认策略一致。它不是三态安装 API 的枚举值。缺键、非法类型及越界值回退跟随，不静默改旧用户策略。
- 接入原有原子偏好保存、启动恢复和按变更字段合并；未修改过隔离选项的旧窗口不会覆盖另一窗口的新选择。单次校验补全不再禁用全局设置，安装期间仍冻结设置。

## 安装关系与保护

MinecraftInstaller 构造器增加只读可空默认策略参数，在实际下载元数据后由现有 PclIsolationPlan 统一分类，不在界面复制 Modable、OptiFine 或非正式版判断。原有三态安装 API 保留兼容。

- 新建且 FollowPcl 时可应用本工具的明确默认；显式 Enabled/Disabled 仍优先。
- 跟随时不传覆盖值，继续读取所选 PCL 的默认，保持原有回退行为。
- 校验补全忽略新默认，保留已有实例设置、旧格式、目录信号与既有全局回退。
- 明确指定策略的现代纯原版同样生成隔离计划，设置随实例一起原子发布。共享 Mods 冲突、取消及回收机制保持不变。
- App 在第一个 Await 前捕获策略并构造安装器，进行中任务不会受之后控件变化影响。CF/MR 及在线整合包不接收该覆盖值，保持强制隔离。

不写 PCL 外部全局设置，不批量迁移已有实例，不更改文件调度、摘要校验、组件安装或搜索逻辑。内部安装夹具代理增加默认策略参数，相关测试签名随之更新，以验证真正提交的值。

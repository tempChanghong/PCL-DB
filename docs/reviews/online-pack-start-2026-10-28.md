基线：`3e3157652ae847b9c1937d2d63bc6f462b4209f6`。

## PCL2 依据

重新读取固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的四份 Git 原始文件，摘要见 `artifacts/online-pack-start/source/manifest.json`。

- `PageDownloadCompDetail.Install_Click` 在名称确认后，为下载、导入加载器绑定目标和终态回调，启动并加入任务列表，然后进入任务管理页。
- `ModModpack.InstallPackCurseForge/InstallPackModrinth` 以任务名阻止重复安装，加载器持有目标版本目录；结果归属于该加载器。

本轮沿用现有 PCL 风格详情、进度页和返回动画，修正 PCL-DB 的任务启动顺序与取消通知边界。

## 复现与修复

在线安装原先在设置 `_busy`、创建任务代次及进入 Try 之前，取消本地归档、搜索和详情读取。同步通知若发起另一个安装动作，可产生两个任务；若请求取消，当时尚无本任务可取消；若抛错，则绕过本任务结果与清理；若切管理页，后续旧 `ShowProgress` 又会把页面切回。与已修复的社区资源安装入口相比，在线整合包仍存在独立缺口。

- 为内部在线安装入口增加忙碌、Mod 写入和关闭门控，重复调用不会取代当前任务。
- 保留安装前目标和路径预检；接受安装后先绑定任务取消源、目标、名称、阶段及结果信息，界面准备与偏好保存也进入原有 Try／Finally。
- 通过既有资源退役方法先解绑搜索、详情、名称、图片与前置读取；本入口保留旧内容时钟到父页面捕获合成画面后，再由原切页机制清理，随后通知旧读取。其他退役调用保留原有即时清理。捕获本地导入读取，使用原有容错取消方法处理；各组取消失败仍继续清理其他捕获源。
- 通知完成后检查本任务取消状态，再调用安装器。早期取消和取消通知错误产生当前任务的明确终态，释放输入门控；较新主页面切换保留其页面与动画。
- 三种启动器的目标、已有实例和外部设置保持，独立重试使用新任务，返回原详情页继续沿用现有卡片和动画机制。

# 本地 Mod 选择动画：录屏复查与修复

基线：`add0e35`。针对用户提供的 `20261027-1510-03.9690565.mp4`（PCL2，12.23 秒）和 `20261027-1510-35.3238521.mp4`（PCL-DB，8.57 秒）。提取总览帧与点击前后 30 fps 连续帧，检查对象是本地 Mod 列表的选择及底栏，不是下载页切换。

## 依据与问题

重读固定 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 `MyLocalModItem.xaml/.xaml.vb`、`PageInstanceMod.xaml.vb`、`ModBase.vb` 和 `ModAnimation.vb`，五份原始 Git 对象／SHA-256 见 `artifacts/video-motion-2026-10-27/source/manifest.json`。

- `MyLocalModItem.Checked`：竖条目标 32 DIP，位置为左侧 -3 DIP；高度变化由 40%／200 ms 弱 Fluent 和 60%／300 ms 弱 Back 并行叠加，30 ms 淡入。取消时 120 ms 收缩，等待 40 ms 后进行 70 ms 淡出。标题分别以 200／120 ms 渐变，禁用项选中时使用较浅的强调色。
- `RefreshColor`：按下整行也有背板缩放及颜色反馈。
- `PageInstanceMod`：只在数量增加时播放底栏弹跳；取消最后一项时保留原计数，90 ms 淡出并以弱 EaseIn 退到 -10 DIP；`ChangeAllSelected` 在现有行上改变状态。

PCL-DB 原实现直接切换竖条 Visibility、直接替换标题颜色；按压反馈仅覆盖行内按钮；底栏退场前把文字改为“已选择 0 个文件”。另沿全选与取消选择追踪发现，它们调用列表重建，会卸载并重新加载全部行，打断行内动画。

## 修复与关系

为本地 Mod 选择增加独立时钟，复用已有 `PclSelectedHeightAnimation` 与 PCL ARGB 字节插值。每次替代从当前显示的高度、透明度和颜色采样，旧完成回调核对所属时钟；选择状态不再通过隐藏竖条控制。参照 `IsVisibleInForm`，窗口外的行直接设置稳定状态，不为全选数百个 Mod 创建不可见的选择时钟；判断还考虑滚动区域裁剪。选中／禁用／可更新颜色分别处理，保留禁用删除线及已有更新提示。

悬停和行内按钮沿原有时钟运行；标题更新、动态主题帧不重启选择几何。关闭动画、输入门控、隐藏、卸载及离页会清理选择时钟并恢复稳定状态。全选和取消选择改为原位更新，只统一刷新一次底栏，不重新挂载列表。最后一项取消时保留旧计数，立即关闭操作输入；重新勾选可以替换正在退场的底栏，旧完成回调不能隐藏它。

这些修改不触碰 Mod 文件、启停写入、更新安装、三种启动器隔离、外部配置和搜索下载内核。

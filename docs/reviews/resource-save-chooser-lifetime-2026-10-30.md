# 社区资源另存为的页面访问归属

基线 83205f67be13212995133bc93a06719e6e9ee167。本轮保留 VB WPF、C# Core、VB 测试、.NET Framework 4.8、配置、资源和现有下载安装内核。

## 复现与原因

SaveCommunityResource 原来在文件选择返回后检查控件和项目引用，但没有核对页面访问代次；两个错误分支也只检查关闭状态。选择器期间离开页面，旧错误仍会写入共享反馈控件；设置页往返后，同一项目和版本行可能仍是原对象，旧选择便被当成当前操作，创建下载任务并切换进度页。

新增用例从真实版本行 Activate 发起保存，注入的文件选择器调用真实 ShowSettings／ShowDownload，分别返回路径或抛出受控 I/O 异常。原实现 56/88、32 项失败，修复后中间候选 88/88；报告与明确退出码见 artifacts/resource-save-chooser-lifetime/baseline、candidate。这是受控交接证明，不证明普通模态窗口中用户必然可以点击被禁用的主窗口，也不估算实际发生频率。

## 修复

- 捕获原有详情、分类和主页面导航代次，同时保留项目、页面及版本行的有效性检查。返回相同项目也必须属于原访问才能接收路径。
- 两个错误分支共用受归属保护的发布逻辑；设置文本后再次确认归属，才显示反馈，防止同步通知接受新页面后旧分支继续操作。
- 正常保存、当前错误、取消、速度校验、选中文件副本和 finally 的选择器门控沿用原流程。

没有新增公开业务 API、配置字段或任务协议，没有修改 C# Core、目录隔离、文件冲突、校验与原子发布，也没有修改动画曲线、时长、标题导航和控件样式。此次将页面代次延伸到文件选择器交接，而非重写下载流程。

## 验证与限制

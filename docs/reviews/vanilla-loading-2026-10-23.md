# 原版版本清单加载展示对齐

日期：2026-10-23。基线：`65e3e3b`。本轮覆盖原版清单首次读取、刷新和离开页面时的加载展示，验证后本地 Commit，暂不推送、打包或发版。

## 源码依据与差异

重新读取未限制 PCL `5ef81e490ae46b1100d61e33d0183094c7a80ca8` 的 `Controls/MyPageRight.vb`、`Pages/PageDownload/PageDownloadInstall.xaml` 及其 VB 代码。规范化副本和 SHA-256 保存于 `artifacts/vanilla-loading/source/`，收尾时重新对照 Git 对象。

PCL 的 PageDownloadInstall 通过 PageLoaderInit 将 DlClientListLoader 绑定到 PanLoad / PanAllBack；PanLoad 是居中的 MyCard，包含“正在加载”的 MyLoading，间距为 20,20,20,17。MyPageRight 先执行 LoaderWait 400 ms，快响应直接进入内容；慢响应先进入加载动画，再从入场结束开始强制停留 400 ms。组件通过各自的 LoadOptiFine / LoadForge 等独立加载器管理，不应一起挂到原版清单的整页等待上。

基线原版清单只有 EmptyVersions 和底部状态文字，没有对应加载卡片。该结论来自精确基线文件 `source/base_MainWindow.xaml.vb` 的源码检查，本轮没有声称运行过修改前的复现场景。

## 修改与边界

- 首次读取原版清单复用上一轮的 PclLoadingPresentation：等待期间收起占位文字，慢请求才创建居中卡片和旋转镐；快响应不创建加载控件。
- 卡片布局和 MyLoading 外观沿用固定 PCL 源码参数及已有 PclLoadingView。动态资源支持明暗主题；控件移除时释放内部动画。
- 抽出 ChangeVersionContent，让加载、成功和首次失败共用原来的目录入场、输入门控和焦点恢复逻辑。等待跟随实际主页面或分类动画结束，不增加第三个动画控制器。
- 发布前复查请求对象、代次、关闭状态、取消和安装状态。入场或最小停留期间切源、重试、取消或开始安装，不允许旧结果覆盖当前状态。取消、失败和窗口关闭清除加载卡片、计时器及等待者。
- 页面隐藏时继续现有元数据请求；返回只恢复展示等待，已就绪数据立即交回缓存。隐藏结果不能重启动画或覆盖当前设置页的动画。
- 刷新已有可用清单时继续保留现有行及列表操作。这是保留 PCL-DB 已约定的缓存刷新行为，本轮只对首次清单的加载展示作 PCL 对齐，并未宣称整个刷新状态机完全等同上游。
- 主清单完成后即结束加载展示。UVMC 补充清单继续独立请求，失败仅更新补充清单提示，不重新显示加载器，也不影响正常版本。
- 初次失败保留现有错误文字与“刷新列表”恢复入口；PCL 的 MyLoading 同时承载失败状态，本轮未重写本工具的错误控件。
- 动画关闭时不增加人工等待。组件并行列表、文件下载调度、校验、隔离、共享 Mods、已有实例设置、原子发布及安装取消源均未修改。

## 复现

PromptResourceTargetAsync 已等待确认退场，并在新弹窗替换时撤销旧交接；但上层 InstallCommunityResource 只检查关闭、项目引用与目标。完成确认时，取消通知或其他 UI 回调可同步切换页面。离开后项目对象仍被保留，往返相同项目也不一定更换它，旧计划因而仍被放行，创建任务或改变保留的下载视图。

新增用例使用真实安装按钮入口与确认按钮，在父请求的取消通知中调用 ShowSettings，或 ShowSettings 后 ShowDownload，保留同一项目与启动器。动画模式暂停已存在的退场时钟，再用原时钟完成退场；不是用修改代次字段伪造导航。原实现 60/108、48 项失败，修复后中间候选 108/108，见 artifacts/resource-install-handoff/baseline、candidate。

这证明受控同步交接存在缺口，不证明禁用的主窗口在真实模态交互中仍能被鼠标点击，也不估计实际发生频率。测试没有取消用户已经开始运行的安装；新增门控位于安装器启动之前。

## 修改

- 发起时捕获原有详情、分类与主页面代次；退场完成后同时检查项目、页面、版本行和启动器目标，再接收原冻结计划。
- 离开或往返后返回的旧计划直接退役，不创建任务、不强制改变新页面或退场时钟；当前正常确认继续等待原退场并启动一次安装。
- 错误反馈采用同一归属检查，设置文本后再核对一次才显示；原取消分支和选择器 finally 清理不变。该错误分支的归属由源码核对，新增定向用例覆盖确认成功与两种导航退役，既有错误／取消回归继续运行。

没有修改 PromptResourceTargetAsync、CompleteOnlinePrompt、动画控制器、曲线或时长，没有新增任务协议或配置字段；C# Core、原生隔离、共享目录、校验与原子发布保持原样。

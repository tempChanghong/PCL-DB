基线 `a8808da`。本轮以 PCL2 的 UI 和样式为主要交付，复查识别、启停、导入、共享目录及动画联动。保持既有配置与文件事务机制，不改版本号、不打包发版。

## 页面与交互修正

### 搜索框与操作栏

固定 PCL `MySearchBox` 使用 40 DIP 卡片、无内边框输入、左侧 14 DIP 搜索图标、右侧 24 DIP 清空按钮与 90 ms 显隐。旧页面是 30 DIP 输入框外加卡片上下内距，实测总高 54 DIP，四周另有输入边框。

本轮局部恢复上述结构和时序，使用当前 PCL 字体、明暗颜色和按压动画。保留 256 字符搜索上限、原离线筛选和搜索焦点保护；清空入口遵守当前页面及动画输入门控，隐藏/卸载/主题变化清理所属时钟。输入文字和空提示使用局部模板的 32/40 DIP 左右留白，不修改其他页面的输入模板。操作按钮改为 35 DIP 高、15 DIP 间距，“打开文件夹”使用 PCL 高亮角色；实际目录与共享提示继续显示。空状态行折叠，读取、取消和错误反馈出现时恢复自动高度，消除空文字留下的约 19 DIP 留白。

### 搜索候选数量与筛选

旧实现先按全库计算三个筛选标签，随后才搜索。已在隐藏表面复现：4 个 Mod 中搜索仅匹配 1 个启用项，仍显示“全部 4／启用 3／禁用 1”；点禁用后空列表仍标记“禁用 1”。

按 PCL `RefreshBars` 先取得搜索候选，再计算启用/禁用数量和最终状态筛选。搜索时首项改为“搜索结果”；无意义的状态标签按上游规则隐藏，当前选中的零数量状态仍保留，避免失去切回入口。保留已有行缓存、重扫及焦点/代次保护。

### 长描述与同步取消

真实归档声明 4096 字符描述、同名启用/禁用文件及重复 ID 时，旧 Tooltip 把描述放在警告之前，截断后完全看不到冲突信息；原截断函数还会将省略号加在上限之外。现在文件名、错误和警告优先，描述在后，省略号计入总上限，截断避免拆开 UTF-16 代理对。文件路径与实际操作名称不截断、不修改。

另以默认 `TaskCompletionSource` 和同步 Token 回调复现：取消返回时操作已经结束、导入重新可用，但状态仍显示“正在等待文件操作退出”。原因是旧处理在调用取消后才写等待文字，覆盖了已完成的回流。现在先发布等待状态，最后触发取消，迟到和重复取消不再改写终态。没有改写 Core 互斥、共享锁或取消回滚。

修前诊断分别在 `artifacts/mod-actions-audit/hidden-warning-3abca8e07ecc48299389c4fd4cadcf9b/` 与 `inline-cancel-057d232f499d4a51bbedae0a350b935a/`。
